# tools/identify_params — 平面 8 参模型参数辨识

配套模型: `include/tcbs/mpc/planar_yaw_model.h`（文件头有完整推导）、默认值: `include/tcbs/mpc/planar_yaw_params.h`。

```
τ = M(q) q̈ + h(q, q̇, g_A, ω_c, α_c)
φ = [ Jbig_eff, Js, Px, Py, fc_big, fv_big, fc_small, fv_small ]   （kNumParams = 8）
```

**关键性质**: 方程对 φ 线性，且回归矩阵 `regressor()` 是**解析式**（不含 φ）⇒ 一次加权线性最小二乘即可；
不可辨识方向（YᵀWY 的零空间）自动**保持先验值**（`defaultModelParams()`），不会发散。
`frictionLambda` 固定 10（不辨识）；几何 `dx/dy`、重力 `g_A`、可选 `τ_offset_*` 不属于辨识参数。

---

## 1. 处理链

| 步骤 | 做法 |
|---|---|
| 读数据 | 任意多个 CSV，**按列名**取值；多余列忽略；缺必需列时打印缺失列名 + 文件实际表头 |
| 角加速度 | `dtheta_*` 段内中心差分 + 3 点平滑（`--smooth=N` 多遍）；`dt` 由 `t` 列逐文件取中位数 |
| held 轴 | `--held=ideal/measured/drop`（见 §3） |
| 时间对齐 | `--align-shift=auto`（默认，搜 −1/0/+1）/ `fine`（0.125 帧步长，τ 线性插值）/ 指定帧数 |
| 加权 | 两轴各按自身力矩 σ 归一化；再按列做 SNR 加权（默认开）；再列归一化 |
| 求解 | 归一化法方程 + SVD 截断（`--trunc`，相对最大奇异值）+ 可选 Tikhonov（`--tikhonov`） |
| 输出 | 数值秩、奇异值谱(前 8)、列共线性、辨识前后残差 RMS、每参数（估计值/变化量/σ）、物理钳制警告 |
| 落盘 | `data/sysid/identified_params.txt`：可直接替换 `planar_yaw_params.h` 里 8 行赋值 |
| 验证 | `--validate=<csv>`：力矩预测 RMS + 开环前向仿真角度误差（先验 vs 辨识） |
| 数据体检 | 指令力矩峰值 ≥ `--sat`(0.98) 报警（饱和样本会污染辨识）；q̈ 差分尖峰剔除；力矩饱和样本计数 |

## 2. 用法

```bash
cd build && cmake .. && make -j8 identify_params

# 基本用法（shell 展开通配；多种激励的数据一起拟合效果最好）
./build/tcbs_identify_params data/sysid/sysid_big_*.csv data/sysid/sysid_small_*.csv

# 推荐（见 §5.6 自检：100Hz + 8192 线编码器时 3 遍平滑显著降低摩擦参数误差）
./build/tcbs_identify_params data/sysid/*.csv --smooth=3 --validate=data/sysid/val_*.csv

# 其它
./build/tcbs_identify_params a.csv b.csv --held=drop --align-shift=fine --trunc=1e-6 --tikhonov=1e-3
./build/tcbs_identify_params a.csv --tilt-deg=10 --truth=Js=0.0174,Px=0.0125   # --truth 仅用于合成数据自检
```

| 选项 | 默认 | 说明 |
|---|---|---|
| `--held=ideal\|measured\|drop` | `measured` | held 轴处理，见 §3 |
| `--align-shift=auto\|fine\|<x>` | `auto` | τ↔状态时间对齐；`auto` 搜 −1/0/+1 帧，`fine` 在 [−1,+1] 上以 0.125 帧步长搜（τ 线性插值），也可直接给帧数（允许小数） |
| `--align-margin=<f>` | `0.01` | 接受非零 shift 所需的最小残差改善；残差改善不足 1% 时**保持自然对齐 shift=0**（否则会追噪声） |
| `--align-band=<f>` | `0.02` | 对齐不确定度带：残差在最优 +2% 内的 shift 区间内各参数的散布（**LS 的 σ 不含这一项**）；0=关闭 |
| `--trunc=<r>` | `1e-7` | SVD 相对截断阈值（越小越相信病态方向） |
| `--tikhonov=<λ>` | `0` | 归一化坐标下的 Tikhonov 正则 |
| `--no-snr-weight` | 开 | 关闭列级 SNR 加权 |
| `--snr-min=<s>` / `--snr-floor=<f>` | `0.05` / `0` | 列 SNR 低于 `snr-min` 直接丢列（该参数保持先验）；权重下限 |
| `--smooth=<n>` | `1` | 角加速度 3 点平滑遍数 |
| `--qdd-max=/-big=/-small=` | `500/2000` | q̈ 差分尖峰剔除阈值 (rad/s²) |
| `--no-joint-weight` | 开 | 不做两轴力矩 σ 归一化加权 |
| `--gravity-a=<gx,gy>` / `--tilt-deg=<deg>` | `0,0` | 重力在**大 yaw 转子系**的平面分量；CSV 若有 `gravity_ax/gravity_ay` 列则逐样本优先使用 |
| `--dx= --dy=` | 取默认 | 覆盖几何偏置（必须与真机一致，否则 P 项有偏） |
| `--max-big-age=<s>` | 关 | 仅当 CSV 有 `big_enc_age`/`big_age` 列时按年龄筛样本 |
| `--sat=<v>` | `0.98` | 力矩饱和告警阈值 |
| `--validate=<csv>` / `--no-fwd-sim` | — | 验证集；跳过开环前向仿真 |
| `--truth=<name=value,...>` | — | 打印真值对比（合成数据自检用，真机不用） |
| `--out=<path>` | `data/sysid/identified_params.txt` | 输出文件 |

## 3. held 轴的三种处理

CSV 的 `axis` 列: `0` = 大 yaw 被激励（小 yaw 被保持），`1` = 小 yaw 被激励（大 yaw 被保持）。

| 模式 | 含义 | 何时用 |
|---|---|---|
| `measured`（默认） | held 轴用**实测** q̇/q̈；两轴方程都进回归 | 通用；模型对任意运动都成立 |
| `ideal` | held 轴 q̇/q̈ **置 0**（位置仍用实测） | 只有 held 轴**确实几乎不动**时才成立。★ 若 held 轴实际被"晃动"（另一轴的惯性反作用、PD 跟随误差），held 轴方程里的实测力矩无法被"静止模型"解释，LS 会把它塞进惯量项 ⇒ **参数会离谱地放大**（自检里 Js 偏差 60 倍，见 §5.3） |
| `drop` | **丢弃 held 轴的方程**，只用被激励轴的方程 | held 轴力矩主要是控制器输出（"污染"方程）时最稳；代价是方程数减半。★ 两轴都必须有激励数据，否则工具直接报错退出 |

## 4. 数据格式

必需列（缺一个就报错并列出文件实际表头）:

```
t, theta_big, theta_small, dtheta_big, dtheta_small, tau_big, tau_small
```

可选列（有就用，没有不影响；**任何多余列都被忽略**，不会报错）:

| 列 | 用途 |
|---|---|
| `axis` | 0/1 = 哪一轴被激励（见 §3）。缺失时 `--held` 退化，工具会打印警告 |
| `held_target`, `mcu2_seq`, `chassis_*` | 本工具不用（仅作采集记录） |
| `big_enc_age` / `big_age` | 仅当显式给 `--max-big-age=<s>` 时用于筛样本 |
| `gravity_ax`, `gravity_ay` | ★**扩展**：重力在大 yaw 转子系的平面分量，逐样本使用（底盘倾斜且大 yaw 会转动时它是随 θ_b 变的；采集侧能从 IMU 直接给出）。缺失则用 `--gravity-a` / `--tilt-deg` 的常数 |

- 列名有常见别名（`tau_big_cmd`、`omega_big`、`time` 等）也能识别；表头顺序任意；容忍 BOM、`\r`、空行、非数值脏行（脏行计数并跳过）。
- `dt` 由 `t` 列逐文件取中位数（预期 0.01）；同一文件内间距跳变 > 1.5×中位数时自动断开成新段，**跨段不做差分**，每段首尾样本的状态不参与拟合。
- 时间列必须严格递增，否则报错。

## 5. 自检（合成数据端到端）

### 5.1 方法

因为没有真机数据，用本仓库模型自己造数据（生成器脚本为临时文件，跑完删除）:

- 用 `planar_yaw_model.h` 的 `integrateStep` 仿真（RK4，每步 5 子步，100 Hz），被激励轴加多正弦力矩（0.55/1.05/1.55 Hz），另一轴由 PD（kp=1.2, kd=0.08）保持在目标角；
- 角度按 **2π/8192 量化**，`dtheta` 由量化角中心差分 + 3 点平滑得到（模拟估计器输出），力矩加 σ=0.002 N·m 噪声；
- 按新 CSV 格式写盘（含 `axis/held_target/mcu2_seq/chassis_*/big_enc_age/gravity_ax/gravity_ay` 列）；
- 真值（`defaultModelParams()` 的默认值列在括号里）:

| 参数 | 真值 | (默认值) | 参数 | 真值 | (默认值) |
|---|---|---|---|---|---|
| `Jbig_eff` | 0.0312 | (0.0240) | `fc_big` | 0.118 | (0.090) |
| `Js` | 0.0174 | (0.0130) | `fv_big` | 0.0440 | (0.030) |
| `Px` | 0.0125 | (0.0000) | `fc_small` | 0.052 | (0.030) |
| `Py` | −0.0068 | (0.0000) | `fv_small` | 0.0135 | (0.008) |

数据集（每集 601 样本、6 s、dt=0.01、单段）:

| 数据 | 激励 | 底盘倾角 | 另一轴 |
|---|---|---|---|
| `D_big` | 大 yaw（峰值 0.35 N·m） | 0° | 小 yaw 保持 0.25 rad |
| `D_small` | 小 yaw（峰值 0.22 N·m） | 10° | 大 yaw 保持 0 |
| `D_both` | 前 3 s 大 / 后 3 s 小 | 8° | 交替保持 0.30 / 0.15 rad |
| `D_val` | 同 `both`，8 s、不同幅值/目标 | 6° | 验证集（不参与拟合） |
| `D_shift` | 同 `D_big`，但 τ 列**人为滞后 1 帧** | 0° | 对齐功能测试 |

`D_big + D_small + D_both`（3594 个方程、数值秩 8/8、无 |corr|≥0.9 的列对）:

|---|---|---|---|---|---|
| `Jbig_eff` | 0.0312 | 0.031341 | **+0.45%** | 0.000193 | ±1.2% |
| `Js` | 0.0174 | 0.017451 | **+0.30%** | 0.000058 | ±0.7% |
| `Px` | 0.0125 | 0.011650 | **−6.8%** | 0.000399 | ±2.0% |
| `Py` | −0.0068 | −0.006064 | **−10.8%** | 0.000270 | ±1.0% |
| `fc_big` | 0.118 | 0.117142 | **−0.73%** | 0.000842 | ±1.2% |
| `fv_big` | 0.0440 | 0.039945 | **−9.2%** | 0.001734 | ±12.5% |
| `fc_small` | 0.052 | 0.051042 | **−1.8%** | 0.000521 | ±0.4% |
| `fv_small` | 0.0135 | 0.012834 | **−4.9%** | 0.000390 | ±8.0% |

（列级 SNR 加权在本例中给出权重 0.998~1.000 —— 自检数据本身信噪比高，SNR 加权主要是诊断用。
奇异值谱 1.393 1.363 1.213 1.057 0.9811 0.5595 0.4382 0.3804，最小/最大 ≈ 0.27。）

- 加权残差 RMS: 先验 0.2960 → 辨识后 **0.1166**（降低 60.6%）；未加权 大 yaw 0.0348→0.0165、小 yaw 0.0286→0.0091 N·m（力矩本身 RMS ≈ 0.126 / 0.091 N·m）。
- 验证集 `D_val`：力矩预测 RMS 大 yaw 0.0326→**0.0192**、小 yaw 0.0317→**0.0085** N·m；
  开环前向仿真（实测 τ 驱动，角度 RMS rad）大 yaw 0.193→**0.0099**、小 yaw 1.411→**0.0414**。
- 只用 `D_big + D_small` 时误差: Jbig +1.9%、Js −0.4%、Px −13.8%、Py −19.1%、fc_big −0.6%、fv_big −10.1%、fc_small −3.6%、fv_small +1.8%
  —— 数据越多越互补（不同倾角/不同激励轴），P 项尤其明显。

### 5.3 三种 held 模式对比（`D_both`，同数据同选项）

| 模式 | 方程数 | 辨识后加权残差 | Jbig_eff | Js | Px | Py | fc_big | fv_big | fc_small | fv_small |
|---|---|---|---|---|---|---|---|---|---|---|
| `measured`（默认） | 1198 | **0.1299** | −2.5% | +0.7% | −0.6% | −6.9% | −1.7% | −2.0% | −0.2% | −9.5% |
| `drop` | 599 | 0.1229 | −7.7% | −0.4% | +6.2% | −15.0% | −6.9% | **+42%** | −6.9% | **+19%** |
| `ideal` | 1198 | 0.5687（差 4.4 倍） | **+16%** | **−50%** | **−137%** | **−209%** | **−41%** | **+139%** | **+16%** | −1.6% |

（各模式数值受对齐选择影响，`ideal` 在 `D_big` 上更极端: `Jbig_eff` 估成 1.198（真值 0.0312），`Js` 估成 1.161。）

结论: **`ideal` 只在"held 轴真的静止"时可用**；只要 held 轴被另一轴的惯性反作用晃出可观运动，
它的实测力矩就无法被"静止模型"解释，LS 会把这份力矩错误地归到惯量项 ⇒ 参数放大几十倍。
`measured`（默认）与 `drop` 都可用；`drop` 方程数少一半、对小 yaw 摩擦更敏感，但能彻底避开
"控制器力矩污染方程"。三种模式的差异本身就是一条诊断信息。

### 5.4 时间对齐

| 数据 | shift=−1 | shift=0 | shift=+1 | 选择 | 说明 |
|---|---|---|---|---|---|
| `D_big`（对齐正确） | 0.16709 | **0.16867** | 0.17007 | `+0` | 最优 −1 相对 0 只改善 0.94% < 阈值 1% ⇒ 保持自然对齐 |
| `D_shift`（τ 滞后 1 帧） | **0.16297** | 0.16598 | 0.16616 | `−1` | 改善 1.81% ≥ 1% ⇒ 接受；参数与"未错位数据"几乎一致（fv_big −10.0% vs −10.1%，fv_small +0.8% vs +0.3%）⇒ **自动对齐有效** |
| `D_shift2`（τ 滞后 2 帧） | **0.16075** | 0.16250 | 0.16336 | `−1` | 方向正确（受搜索范围 −1 限制），残差改善 1.09% |

`--align-shift=fine`（0.125 帧步长）可以看到残差曲线是**双峰、极平**的（`D_big` 上 −0.625 与 +0.375 两个极小值只差 0.03%），
这与"中心差分 q̈ 覆盖 ±1 帧、而 τ 是零阶保持 ⇒ 等效配对准心在 j−0.375…−0.5 帧"吻合。
因此: **残差无法判定亚帧对齐**，但 **fc/fv 对半帧错位非常敏感**（`fv_big` 在带内可从 0.0409 变到 0.0598，±19%）。

工具因此提供两条针对性输出:
1. `--align-margin`（默认 1%）：改善不足就不动对齐，避免追噪声；
2. **对齐不确定度带**：把"残差在最优 +2% 内的所有 shift"下各参数的散布打印出来，
   作为 **LS 的 σ 之外的系统不确定度**（自检里 `fv_big` 的真实误差 0.0045 落在带内，
   而 LS 的 σ=0.002 明显偏小 ⇒ 看 σ 会过于乐观）。

### 5.5 对齐（整数帧）对摩擦参数的影响（`D_big + D_small`）

| shift | fc_big | fv_big | fc_small | fv_small | Jbig_eff | Js | Px | Py |
|---|---|---|---|---|---|---|---|---|
| −1 | +2.8% | **−48%** | −2.7% | **−23%** | +5.1% | +1.2% | −23.9% | −28.8% |
| **0（工具默认选择）** | **−0.6%** | **−10%** | **−3.6%** | **+1.8%** | **+1.9%** | **−0.4%** | **−13.8%** | **−19.1%** |
| +1 | −4.3% | +28% | −4.5% | +26% | −1.6% | −2.4% | −4.4% | −10.4% |

它的误差主要由"τ 的零阶保持 vs q̈ 的中心差分"这条半帧错位决定，而不是由测噪决定。

### 5.6 其它自检项

- **`--smooth`**: 同一数据（`D_big+D_small`）`smooth=1` 时 Jbig −6.1%/Js −6.1%/fv_big +36%/fv_small +34%，
  `smooth=3` 时 Jbig +1.9%/Js −0.4%/fv_big −10%/fv_small +1.8% —— 激励带宽 ≤2 Hz、采样 100 Hz，
  多平滑几遍几乎无偏（3 遍在 1.5 Hz 处衰减 <1%）却把差分噪声压低约 1.7 倍。**推荐 `--smooth=3`**。
- **SNR 加权**: 自检数据信噪比高，各列权重 0.997~1.0（打印在报告里）；把 `--snr-min` 调到 1000
  可复现"列被丢弃"路径——全部参数保持先验、σ 报 `inf`，并提示"数值秩 0 < 8，检查激励"。
- **共线性诊断**: 关掉关节加权时立刻报出 `Px ↔ Py corr = −0.929`，解释了**水平底盘下 P 项几乎不可辨识**
  （它只通过 `d·Q` 耦合项进入，与惯量项高度共线）。自检中 P 项只有在**倾斜底盘**（8°~10°）+ θ_s 变化的数据里才恢复到 7~11% 误差。
- **截断/正则**: `--trunc=0.3` 得到"数值秩 5、3 个方向保持先验、σ 全部 ∞"；`--tikhonov=1e-3` 正常收敛。
- **饱和告警**: 用峰值 1.6 N·m 的激励（限幅 1.0）生成数据，工具报出"大 yaw 峰值 1.0047 N·m、52 个样本 ≥0.98"并给出警告。
- **鲁棒性**: 表头乱序 + 额外列 + 脏行 → 正常读取（脏行计数）；缺列/空文件/文件不存在/无参数/非法选项 → 均给出明确中文错误。

## 6. 已知限制

1. **Px/Py 需要倾斜或 θ_s 大范围变化**才有足够信息；水平底盘 + θ_s≈0 时它们与惯量共线（共线性诊断会报出来）。
2. **fc/fv 的系统不确定度 ~±10~40%**（§5.4/§5.5），主要来自亚帧时间对齐与"零阶保持力矩 + 中心差分角加速度"的固有错位；
   报告里的对齐带是这个不确定度的估计，**不要只看 LS 的 σ**。
3. 本工具**不含底盘耦合**：`base_omega/base_alpha` 一律取 0（按需求）。若底盘会绕关节轴转动，
   需要在采集侧记录并在模型里带上，否则该耦合会漏进摩擦/惯量项。
4. 力矩是**指令力矩**：电控力矩常数若有偏差，会被摩擦/惯量整体吸收（闭环仍可用，但不能反推物理 Kg）。
5. 编码器量化在 100 Hz 下会让"零速附近的速度符号抖动"，这是库仑摩擦被低估（自检里 fc 系统性 −1%~−9%）的主因；
   想更准需要更高采样率/更高分辨率，或让被激励轴的速度远离零（避免长时间停在 ±1 计数抖动区）。
