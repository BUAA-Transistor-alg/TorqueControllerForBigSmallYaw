# 大 yaw 背隙: 3-DOF 模型、在线量、数据与辨识

> 本文是**背隙这一条线**的完整说明：为什么必须建 3-DOF、δ/β/γ 各是什么、哪些量能离线标定、
> 哪些只能在线估计、数据要采什么列、torch 辨识怎么用这些参数、MPC 里怎么接。
> 平面 2-DOF 耦合模型本身的推导仍见 `docs/model.md`；数据列清单见 `docs/sysid_data.md`。
>
> 最短结论：
> 1. 大 yaw 的**电机编码器角**与**云台角**之间隔着背隙（同步带 + 齿轮），两者**解耦** ⇒
>    电机角**不能**再用来修正云台角/角速度（该路径已完全删除）。
> 2. 云台角/角速度来自「头 IMU + 小 yaw 编码器 + 底盘 IMU」的严格反解；电机角来自 MCU 编码器
>    （延迟 + 值保持链路）。
> 3. 模型里 θ_motor 是**独立状态**，力矩经 `τ_t = k·[dz(Δ)+γ·Δ] + c·Δ̇`（Δ = θ_motor − θ_platform − β）
>    传递。δ/k/c/γ/J_motor/电机摩擦/β **全部由 torch 辨识直接拟合**，没有任何"特殊"近似路径。
> 4. **只有宽度 δ 是静态量**；死区中心 β 随电机/云台共同旋转、且云台角由 IMU 推出会漂移 ⇒
>    β 由估计器**在线**给出（`Estimate::backlash_center`），实机不要用离线常数。

## 1. 物理图像与为什么是 3-DOF

### 1.1 现象

大 yaw 在"持续给一个方向的力矩、贴在背隙一侧"时抖动明显减小；双向小幅摆动/换向时，
电机力矩会先走完一段"空行程"才传到云台。小 yaw 没有背隙（直驱/无反向间隙）。
背隙里有一部分来自同步带传动（两侧接触有弹性，但弹性范围很小），中间大部分是齿轮背隙
（几乎完全自由）。

因此"指令力矩 ⇒ 云台力矩"之间有一个**强非线性环节**：

* 死区内（|Δ| < δ/2，Δ 为传动相对角）几乎不传力；
* 死区外是"小弹性 + 大刚度接触"，需要**接触刚度 k** 与**接触阻尼 c**；
* 换向时必须先把空行程走完 ⇒ 若把 τ_cmd 直接当成云台输入，拟合器会把它误当成"摩擦更小"，
  系统性低估 `fc_big`/`fc_small`（2-DOF 时代的实测：`fc_big −55%`、`fc_small −72%`，
  用实测 Δ 反算 τ_t 的近似路径也只能补到 `−37%/−23%`）。

### 1.2 状态与方程（`planar_yaw_model.h::eomBacklash`）

```
q = (θ_motor, θ_platform, θ_small)          # 电机 / 大 yaw 云台 / 小 yaw
u = (τ_cmd, 0, τ_small)                     # 只有"电机"被大 yaw 力矩驱动

Δ  = θ_motor − θ_platform − β
τ_t = k·[dz(Δ) + γ·Δ] + c·Δ̇                 # 传动扭矩（电机受到 −τ_t）
dz(Δ) = relu_ε(Δ − δ/2) − relu_ε(−Δ − δ/2)  # 平滑死区, relu_ε(x)=½(x+√(x²+ε²)), ε=1e-4

M = blkdiag(J_motor, M2)                    # M2 = 平面 2-DOF 云台/小 yaw 子块
h[0] = τ_t + fc_motor·tanh(λ·θ̇_motor) + fv_motor·θ̇_motor + τ_off_motor
h[1] = h_b − τ_t
h[2] = h_s
M·q̈ = u − h        ⇒     q̈ = M⁻¹(u − h)
```

要点：

* 云台/小 yaw 子块 `(M2, h_b, h_s)` 与 2-DOF 的 `eom()` **一字不改地复用**（`q_b ← θ_platform`），
  所以平面耦合（`Q = R(θ_s)P`、`μ = 2(dy·Qx − dx·Qy)`、重力项、底盘 ω_c/α_c 耦合）完全没有变；
* M 是**块对角**：电机行与云台行之间只有 `τ_t` 这条力耦合，没有惯量耦合
  ⇒ 求逆只需 1 个标量除法 + 1 个 2×2 逆（快且不易写错）；
* `Δ̇` 与 `θ_small`/`θ_platform` 的耦合（`−τ_t` 同时进电机行与云台行）保证内力自洽
  —— `dz` 的 `relu_ε` 是 C¹ 的，所以 `Δ→0` 时不会出现刚度爆炸。

### 1.3 β、δ、γ 的语义（**这三个最容易搞错**）

| 记号 | 名称 | 含义 | 能不能离线定？ |
|---|---|---|---|
| δ | **宽度** | 传动能"空走"的总范围（两侧接触边界之间的距离） | ✅ 静态量：装配决定，唯一能离线标定的量 |
| β | **中心** | 死区中心相对 `θ_motor − θ_platform` 零点的偏置（`Δ = θ_m − θ_p − β`） | ❌ **在线**估计（见 §2） |
| γ | **直通项** | 死区内部的线性残余刚度 `k·γ·Δ`（同步带弹性） | ❌ **不拟合**：默认**冻结**在 0.002（它的定位只是死区内的**梯度引导**；放开会被优化器拿去"填"刚性接触的台阶，见 §7.6.2）。要放开用 `--no-freeze-backlash-through` |

关于 β 为什么不是常数（用户实测结论）：

* 死区是"两侧接触面之间的距离"，在**相对坐标**里它的宽度 δ 是装配量；
* 但把 Δ 表达成 `θ_motor − θ_platform` 时，`θ_platform` 由 IMU 反解 ⇒ 有缓慢漂移；
  同时电机/云台共同旋转时，瞬时接触点在齿面上也会移动；
* 结论：**只有宽度是量得准的，两个边界的位置量不准** ⇒ 用带遗忘的滑动 min/max 在线定中心。

### 1.4 数值稳定性（显式积分的硬约束）

接触模态频率 `ω = √(k/μ_red)`，`μ_red = J_motor·J_platform/(J_motor+J_platform)`。
C++ 提供 `recommendedBacklashStiffness(p, dt, rk4)` 给出步长允许的最大 k：

* `dt = 10 ms`、`substeps = 4`（⇒ `hh = 2.5 ms`）、`J_motor=0.006`、`J_platform≈0.07`
  ⇒ `μ_red ≈ 5.5e-3`、`k_max ≈ 6755 N·m/rad`；
* 当前默认 `k = 200` ⇒ `ω ≈ 190 rad/s` ⇒ 10 ms 一步**已经在显式稳定边界上**
  ⇒ 辨识的 `substeps` 默认取 **4**（不像 2-DOF 时代取 1）；MPC 侧同样必须 `substeps ≥ 4`；
* 真机若把 k 标得更大，必须同步加大子步数，否则仿真/预测会发散
  （Ceres 求解器会直接报 `Residual and Jacobian evaluation failed`）。

## 2. 在线量：β 与底盘 IMU 的延迟补偿（`YawStateEstimator`）

### 2.1 Δ 与 β 的在线估计

`Estimate::backlash_center` 是**β 的在线值**（直接用 `ModelExo::backlash_beta` 喂给 MPC）：

```
Δ_raw(T) = θ_motor(延时补偿后) − ψ_platform(实时) + ψ_chassis(延时补偿后)
滑动 min/max（各自以时间常数 backlash_center_tau_s = 3 s 向当前值遗忘）
β = ½(max + min)        width_obs = max − min   （≈δ，诊断用）
```

* 极值分别向当前值遗忘 ⇒ O(1) 近似滑窗：云台双向旋转时**一个时间常数内两侧翼都会被访问**到；
* `width_obs` 只作诊断：它会被链路延迟/保持虚增，**不要**当 δ 用；
* δ **不做**在线修正（用户明确要求"不要"）。
* ★ **只用"刚刷新的样本"更新极值**（`kBacklashFreshS = 20 ms`，从"首次看到该新样本"起算）:
  `θ_motor` 在两次样本之间是按角速度**外推**的，年龄越大外推误差越大（≈½·α·age²，
  背隙内自由段电机加速度可以很大）—— 拿旧样本外推出来的值去撑极值会把 Δ 的极差撑得
  远大于 δ、把中心带偏。实测（`python/scripts/collect_sysid.py --sim-rigid` 的数据）:
  不门控时 β 误差最大 55 mrad；门控后（100 段刚体环境数据实测）大 yaw 段的 β RMS
  从 24.6 → **14.1 mrad**、最大 47 → 37 mrad。

### 2.1.1 β 的可观测性（**实测结论，很重要**）

用"真值 Δ"离线算 `center = (max+min)/2`（= 该做法的**天花板**），按激励轴分开看：

| 数据段 | 观测到的 Δ 极差 | oracle 中心误差 | 在线估计（`backlash_center`）误差 |
|---|---|---|---|
| **大 yaw 被激励**（会往返穿越死区） | ≈ δ（0.087~0.090） | **0.1~0.6 mrad** | **14 mrad RMS**（门控后；受**电机角估计误差**限制） |
| **小 yaw 被激励**（大 yaw 被 PID 守位） | 0.003~0.016 | **37~44 mrad**（无意义） | 42 mrad RMS |

⇒ 两条结论:
1. **只有"往返穿越死区"的数据段才能给出 β**；守着不动时死区中心在原理上不可观测
   （用户早就说过"唯一能确定的是宽度而不是两边的位置"）。
   在线估计器靠**滑动窗跨段保留**旧极值把这一点救回来，但遗忘会让它慢慢退化。
2. 即便在大 yaw 段，在线 β 也被**电机角估计误差**卡在 ≈25 mrad（≈0.3δ）——
   而用真值 Δ 时是 0.3 mrad。也就是说 β 的精度上限由"编码器延迟 + 一阶外推"决定，
   不是由 min/max 窗决定的。（在 `--sim-rigid` 数据上可以直接用
   `theta_true_motor/theta_true_platform` 两列复算这个天花板。）

### 2.2 底盘 IMU 也是"延迟 + 值保持"链路

底盘 IMU 与大 yaw 编码器**走同一条 MCU2 链路**（同一新样本序号、同一刷新时刻、同样被保持），
所以它也必须做延迟补偿，否则云台关节角直接错：

```
θ_p = ψ_platform − ψ_chassis
    ψ_platform : 头 IMU 反解，**实时**
    ψ_chassis  : 被保持的底盘 IMU ⇒ 一阶延时补偿
                 ψ_c(T) ≈ ψ_c(样本) + ω_c(样本)·年龄,  年龄 = T − 见到该新样本的时刻 + transport_delay
```

* 底盘**没有**第二个实时传感器（大 yaw 那边有 IMU 陀螺可以连续外推），所以只能用**被保持的
  底盘角速度**外推；底盘角速度本身变化慢，一阶足够；
* 外推时间上限取 `stale_age_s`（链路停流时不让它无限增长）；
* **角速度本身不做外推**（外推角速度需要角加速度，没有可信来源）⇒ `chassis_yaw_rate` 是
  零阶保持值，误差 ≈ |α_c|·年龄，只以 `μ·ω_c` 的小耦合进入模型；
* 不做补偿的代价：底盘以 ω_c 转动时，`θ_p` 误差 = ω_c·年龄（最长可达一个保持周期）。
  单测 `tests/test_yaw_state_estimator.cpp` 的 `[1]`/`[3]` 两个场景（0.4 Hz / 0.07 Hz 底盘摆动 +
  MCU2 值保持）分别断言了"补偿后 vs 未补偿"的对比。

### 2.3 已经删除的东西（不要再加回来）

* ❌ 用编码器角速度去修正云台角速度的互补滤波/偏置校正：编码器量的物理含义是**电机侧**，
  与云台侧隔着背隙，原理上就是错的；
* ❌ 用被保持的底盘方位角直接算 θ_p（不做补偿）；
* ❌ 用小 yaw 编码器或电机编码器去"补"云台角的绝对基准。

## 2.4 ★ 仿真环境 2: 刚性接触 + 随机漂移 β（`collect_sysid.py --sim-rigid`）

只用于**采集测试数据**（用户要求）。与默认 dry-run 被控对象（`τ_t = k[dz(Δ)+γΔ]+cΔ̇`）相比:

| | 默认（平滑背隙） | `--sim-rigid`（本环境） |
|---|---|---|
| 死区内 | `k·γ·Δ`（微弱弹簧，给梯度） | **`τ_t ≡ 0`**（完全自由，连阻尼都没有） |
| 接触后 | 弹簧 `k=200` + 阻尼 `c=2` | **刚性锁定**（k = ∞）: 电机与云台合并成 2-DOF，接触力由电机行反解 |
| 撞击 | 弹簧吸收（连续） | **完全非弹性冲击**（广义动量守恒 + 冲击后相对速度 = 0） |
| β | 恒 0 | **每条数据重新随机** `β0 ~ U(−0.3δ, +0.3δ)` + 微弱漂移 `A = 0.05δ, T = 30 s` |

实现要点（`RigidBacklashPlant`，只用 Python，**不**进 C++）：

* 死区/接触是一个**单向刚性约束**：贴 +δ/2 时若反解出的 `τ_t < 0`（需要"拉"）⇒ 约束释放回自由段；
* 自由段用 RK4 + **二分定位穿越时刻**（40 次二分）⇒ 撞击点精确、Δ 严格不越界；
* 在闭锁段用 2-DOF 状态 `(θ_platform, θ_small)` 积分，`θ_motor = θ_platform + β + s·δ/2`
  代数恢复 ⇒ Δ 恒等于边界、不会漂移；
* β 在**每个控制周期内视为常数**（漂移率 ≲1e-3 rad/s，10 ms 内变化 <1e-5 rad ≪ δ）
  ⇒ 事件检测简单、边界不随时间瞬变。

数据里额外多出 8 列（实机这 8 列恒 0，只表示"未知"）:
`backlash_center`（在线估计，**运行期真用的就是它**）、`backlash_beta_true`（真值，诊断）、
`theta_true_*` / `dtheta_true_*`（真值状态，用于分离"模型误差"与"状态估计误差"）。

辨识侧对应三个开关:
* `--beta-mode=auto`（默认）: 有 `backlash_center` 列就用它当**逐样本外生量**（= 运行期做法），
  β 不再参与拟合；`--beta-mode=true` 用**真值** β（只用于仿真数据，**上限对照**）；
  `--beta-mode=fit` 退回"拟合一个全局常数 β"（老数据/消融）；
* `--state-mode=true`: 用真值状态当初值与拟合目标（**上限对照**，把模型误差与
  电机状态估计误差分开）；
* `--batch-segments`: 每 epoch 仍对每段抽一个 0.1 s 片段，但把所有段拼成一个 batch 做
  **一次** Adam 步（损失 = 各段损失均值 = 原配方各段梯度的平均）。100 段 × 1000 epoch
  时逐段更新要 ~9 h，全批只要几十分钟 —— 这是能把"1000 epoch"跑完的前提。

## 3. 数据：采什么、怎么用

采集脚本（`python/scripts/collect_sysid.py`）落盘**收到/下发/估计的全部量**。
3-DOF 辨识只需要其中 4 组，但建议全留（便于复核）：

| 用途 | 列 | 说明 |
|---|---|---|
| 电机状态 | `theta_big_motor` | MCU 编码器 + **一阶延时补偿**（模型状态 θ_motor） |
| 云台状态 | `theta_big_platform` | IMU 反解 θ_p = `platform_azimuth − chassis_azimuth` |
| 小 yaw 状态 | `theta_small` | 可信编码器 |
| 输入 | `tau_big`, `tau_small` | **本拍实际下发**的两轴力矩 |
| 诊断（不直接拟合） | `theta_big_motor_meas`, `big_enc_age`, `chassis_imu_age`, `chassis_azimuth`, `base_omega_*`, `dtheta_*` | 延迟标定 / δ 独立校验 / 复核用 |

* 角速度（`dtheta_*`）**一律由角度列用「中心差分 + 3 点平滑」重算**当拟合目标：
  记录里的角速度通道在被保持链路上会有台阶与刷新尖峰（早期用 `c·Δ̇` 近似 τ_t 时，
  就是它把 loss 从 17 带飞）；
* `theta_big_platform` 是**必需列**：12 列老数据没有它 ⇒ 3-DOF 辨识会**跳过该文件并提示重采**；
* 采集工况要求**底盘静止**（倾斜 ≠ 底盘运动）⇒ 模型里 `base_omega = base_alpha = 0`；
  想用真实倾斜激发 `P`，只改静置姿态（`--tilted`/`--tilt-rolling`），底盘仍然不动。
* ★ **保持段（文件名带 `_hold`）默认只取前 3 s**（`--hold-max-sec`，0 = 不截断）：
  保持段里"到位 + 稳定判据满足"之后的绝大部分是静止（实测后段 std 比前 3 s 小 10~800 倍），
  留着白费算力、还会把参数往"零速摩擦"方向拉；而**开头那段正是大角度阶跃**（最有价值）。
  普通收集段（3 s 激励段）不截断；采集脚本不参与这件事。

## 4. torch 辨识（16 参，直接拟合）

命令入口：`python3 python/scripts/identify_params_torch.py --data='data/sysid/*.csv'`。

### 4.1 参数向量（顺序固定）

| # | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 名 | `Jbig_eff` | `Js` | `Px` | `Py` | `fc_big` | `fv_big` | `fc_small` | `fv_small` |
| 单位 | kg·m² | kg·m² | kg·m | kg·m | N·m | N·m·s/rad | N·m | N·m·s/rad |

| # | 8 | 9 | 10 | 11 | 12 | 13 | 14 | 15 |
|---|---|---|---|---|---|---|---|---|
| 名 | `backlash_delta` | `backlash_k` | `backlash_c` | `backlash_through` | `Jmotor` | `fc_motor` | `fv_motor` | `backlash_beta` |
| 单位 | rad | N·m/rad | N·m·s/rad | — | kg·m² | N·m | N·m·s/rad | rad |

* 天然为正的参数走 log 参数化 `φ = exp(raw)`，`Px/Py/β` 是自由参数，
  **没有任何上下界 / clamp / 投影 / 惩罚项**；
* ★ **`γ`（`backlash_through`）默认冻结**在 `--backlash-through` 的初值（0.002）上、不参与拟合
  —— 它只是死区内的梯度引导；放开它会让 δ/γ 一起跑飞（§7.6.2），而留出误差几乎不变。
  `--no-freeze-backlash-through` 可复现"γ 自由"的消融；
* `backlash_smooth_eps`（ε=1e-4）与几何 `(dx, dy)` 是**固定量**，不辨识。

### 4.2 拟合目标与配方

* 输出误差法：以记录的 `(τ_cmd, τ_small)` 为输入，从记录初值 `(θ_motor, θ_platform, θ_small)`
  出发做 **3-DOF 可导前向仿真**，最小化 3 个通道的角度 MSE（先 wrap）+ 角速度 MSE（等权）；
* 通道按 `--fit-axis` 加权：`big` ⇒ 电机+云台；`small` ⇒ 只小 yaw；`both` ⇒ 三个通道平均；
* 默认配方 = 原仓库 `param_ident.py` 同款：`epochs=1000`、每步随机 10 步片段（0.1 s）、
  Adam `lr=3e-4` 常数、RK4、`substeps=4`、无 LBFGS；
  · `--eval-every=N`（配合 `--val-data`）: 每 N 个 epoch 在**留出集**上算一次开环 RMSE，
    最后画「留出误差 vs epoch」学习曲线（`ident_learning.png`）—— 这是判断"多训练有没有用"的
    唯一可靠曲线（训练 loss 是单片段随机采样的，噪声很大）；
  · **耗时**（本机 18 核，11 段 × 1000 epoch）：默认 `--threads=1` 约 **2 h**；
    用 `--substeps=2 --threads=2` 约 **35 min**（实测 0.178 s/步 vs 0.545 s/步）——
    代价是最大可稳定 k 从 6755 降到 ~1700（k≈200 时余量仍 8×），
    且数值误差 5e-3 rad / 0.04 rad/s 仍**低于电机通道自身的噪声**（0.009 rad / 0.23 rad/s）；
  · `substeps` 与 MPC 的 `DualYawMpcConfig::substeps` 同源，改一处要一起核；
* `θ_motor` 的记录值把 δ/k/c/J_motor/电机摩擦**钉住** —— 换向时电机先空走 δ 而云台不动，
  这条信息只有把电机当第 3 个状态才用得上（这正是"直接拟合"相对"τ_t 近似"的优势）；
* `γ` 的梯度引导作用：死区内 `dz` 的梯度≈0，若初值让数据整段落在死区里，k 完全拉不动；
  `k·γ·Δ` 提供非零梯度。自检 `--selftest` 里的第 16 项就是验收"16 个参数的梯度都非零"。
  **但 γ 本身默认冻结**（它是"引导"，不是"被辨识对象"）——§7.6.2 给了放开后的后果。

### 4.3 自检（`--selftest`）

| 编号 | 内容 |
|---|---|
| 1–2 | `Y·φ == ID`（回归矩阵）、`Y == ∂ID/∂φ`（数值偏导） |
| 3–4 | 2-DOF 子块 torch vs numpy（加速度 / rollout） |
| 5–7 | 重力通道、逐样本重力、倾斜前向仿真一致性 |
| 8–11 | `P` 方向约束、参数化往返、log 参数化无界性 |
| 12 | 半隐式欧拉 torch vs numpy 逐位一致 |
| **13** | **3-DOF 装配 == 2-DOF 子块 + τ_t**（逐行验证 `h[1]=h_b−τ_t`、`h[2]=h_s`、电机行） |
| **14** | 3-DOF 正/逆动力学往返（`M·(M⁻¹(u−h)) + h == u`） |
| **15** | 3-DOF 加速度与 rollout（rk4/euler）torch vs numpy |
| **16** | **16 个参数的梯度都有限且非零**（背隙那 8 个尤其重要） |
| **17** | β 确实影响轨迹（死区中心偏置） |

### 4.5 δ 的独立校验（不是前置步骤）

`python/scripts/calibrate_backlash.py` 只做两件事：给拟合一个**初值**、以及**交叉校验**
（若它的 pooled δ 与拟合值差很多，说明数据/时延有问题）。它按
`|θ̇_platform| ≤ --rate-max` 且 `big_enc_age ≤ --age-max` 门控 —— 门控是**必须的**：
值保持期间电机角是旧的、云台却在动，差值里混入平台位移会虚增 δ
（无门控时在无背隙的仿真数据上都能估出 1.63°）。

## 5. MPC / 控制器里怎么接

* `Input::q[3] / qd[3]`：`{θ_motor, θ_platform, θ_small}` 及对应角速度；
  `ModelExo::backlash_beta = est.backlash_center`（在线值）；
* `Output::pred_q[3] / pred_qd[3]`；`pred_joint[2] = {θ_platform, θ_small}`（关节角）；
* 预测里的世界方位角：`ψ_big = ψ_c(t) + θ_platform`（**云台侧**，不是电机侧）；
* 下发的**位置/速度/力矩控制对象都是电机**：
  `pkt.yaw_big_target_angle = θ_platform* + (θ_motor − θ_platform)当前偏置`，
  即"目标云台角 + 当前传动偏置换算到电机"；
* 外部接口（C++/C API）的目标语义**不变**：仍然是**世界系方位角**；
  `Estimate::big_joint_angle` 仍是**电机侧**（旧名兼容），云台侧请用 `big_platform_angle`
  或 `platform_azimuth`；
* 抗抖：模型内建了"死区内几乎不传力"这件事之后，MPC 自己会决定要不要穿过死区；
  若真机仍有抖，优先调 `r_big_torque` / `rd_big_rate`（力矩与力矩速率的代价权重），
  不要靠"持续偏置力矩压在一侧"（那只是掩盖）。

### 7.1 模型一致性（`--selftest`，全部 PASS）

| 检查 | 实测 |
|---|---|
| 3-DOF 装配 == 2-DOF 子块 + τ_t | 5.7e-14 |
| 3-DOF 正/逆动力学往返 | 5.7e-14 |
| 3-DOF 加速度 torch vs numpy | 0 |
| 3-DOF rollout（rk4 / euler）torch vs numpy | 1.3e-15 |
| 16 参梯度 \|∂loss/∂raw\| | ∈ [2.6e-2, 1.2e2]（都 > 0 ⇒ γ 的梯度引导作用在） |
| β 对轨迹的影响 | 1.5e-2 rad（非零） |

另外用 `collect_sysid.PlanarYawPlant`(真被控对象, RK4/0.05 ms) 与辨识脚本的
`simulate_backlash_np` 跑同一条力矩轨迹（1 s、±0.2 N·m 随机）：

| 积分器 | `substeps` | max\|Δθ\| | max\|Δθ̇\| |
|---|---|---|---|
| euler | 4 | 6.4e-3 rad | 0.126 rad/s |
| rk4 | 4 | **7.0e-4 rad** | **3.9e-3 rad/s** |
| rk4 | 20 | 8.7e-6 rad | 2.0e-4 rad/s |

⇒ 这就是把辨识默认积分器改成 **rk4/substeps=4** 的依据（euler 的数值角速度误差与损失里
的角速度项同量级，优化会去"拟合积分器"）。

> ⚠ 这一轮还查出并修掉了 dry-run 被控对象的一个真 bug：`PlanarYawPlant._h()` 把
> **电机角速度**当成了云台角速度（`tb, ts = qd[0], qd[1]`，应为 `qd[1], qd[2]`）。
> 它与 C++ `eomBacklash` 的差别只有把 `_accel` 与 C++ 逐行对照才能发现 —— 修好之后
> 上面的 1e-5 量级一致性才成立。**教训: 平移模型时一定要做"同输入同轨迹"的数值对照。**

### 7.3 拟合参数能否控制（torch 16 参辨识 → MPC 闭环）

在一批 **dry-run 仿真数据**（11 段：6 激励 + 5 保持；模型与被控对象同方程、同参数）上：

| | 电机角 ° | 云台角 ° | 小 yaw ° | 电机/云台/小 yaw 角速度 rad/s |
|---|---|---|---|---|
| 准确参数（窗口 0.1 s） | 0.518 | 0.082 | 0.067 | 0.229 / 0.022 / 0.019 |
| 准确参数（整段开环） | 2.269 | 2.055 | 1.077 | — |

* **电机通道的 0.518° 不是模型误差**，而是数据里 `theta_big_motor` 这一列本身的噪声：
  它是估计器"被保持样本 + 一阶速度外推"的**估计值**（误差 ~½α·age²），不是编码器真值；
  云台/小 yaw 两列是直接测量（0.08°/0.07°）。这一点决定了电机通道的可信度上限，
  也是后续是否要给"电机原始列 + 链路时延模型"加进损失函数的依据。
* 用**真值**作初值拟合 200 epoch：所有参数都留在真值附近（δ 0.0873→**0.0881** rad（+0.9%）、
  k 200→**195.1**（−2.4%）、c 2.0→**2.35**（+18%）、J_motor 0.006→**0.00647**（+8%）、
  `fc_motor` 0.030→0.0304、`fv_motor` 0.010→0.0103；`γ` 0.002→0.0084），
  只有 `Px/Py` 往噪声里跑（见 §7.3 末条 / `--freeze-params`）—— 说明**真值就是（近）不动点**。
* 把这组拟合参数塞进 MPC（plant 用真值）：

| 场景 | 准确参数 RMS | 拟合参数 RMS |
|---|---|---|
| 阶跃 0.6 rad | 0.0277 | **0.0269** |
| 大阶跃 1.2 rad | 0.1636 | **0.1631** |
| 正弦 0.3 rad @0.5 Hz | 0.0066 | **0.0066** |

  失败数 0、求解均 ~2 ms ⇒ **拟合参数可用**。
* 从 CAD 占位初值（`Jbig_eff=0.024` vs 真值 0.050、`fc_big=0.090` vs 0.220、
  `fc_small=0.030` vs 0.0973）出发的收敛很慢（log 参数化 + Adam 3e-4），200 epoch 后：
  `Jbig_eff=0.0303`、`fc_big=0.1132`、`fc_small=0.0408`（仍差 1.6~2.4 倍），
  但**背隙那 8 个参数已经基本到位**：δ=0.0863 rad（−1.2%）、k=200.0（−0.02%）、
  c=2.47（+23%）、J_motor=0.00745（+24%）、电机摩擦 +20~26%、γ=0.0087、β=−0.0012。
  窗口 RMSE 同时从 0.772/0.403/0.533° 降到 0.598/0.241/0.322°，说明拟合方向是对的、
  只是平面参数需要更多 epoch。用这组参数闭环（plant 真值）：

| 场景 | 准确参数 RMS | 真值初值 200ep | CAD 初值 200ep |
|---|---|---|---|
| 阶跃 0.6 rad | 0.0277 | 0.0269 | 0.0373 |
| 大阶跃 1.2 rad | 0.1636 | 0.1631 | 0.1699 |
| 正弦 0.3 rad @0.5 Hz | 0.0066 | 0.0066 | 0.0131 |

  ⇒ 三组都**不发散、失败数 0**；欠收敛的拟合会让误差涨 35~100%，但仍在可用范围。
  所以 `default_param_vector()` 现在默认用 `planar_yaw_params.h` 里**已经在用的那组值**
  当初值（实机日常用法是"有值 → 重采 → 微调"），要复现"从零辨识"再显式传 `--init-vector`。
* 真值初值跑 200 epoch 时看到的**系统性偏离**很有信息量：`Px/Py` 往噪声里跑（不可观测量，
  见 §8.6）；`γ` 从 0.002 涨到 0.0084（死区内部被塞进 `k·γ ≈ 1.6 N·m/rad` 的线性刚度）——
  这是**电机通道目标噪声**（估计器外推误差）在找出口，`k·γ` 的绝对值仍很小、对闭环无碍，
  但如果实机拟合也把它顶得很大，就说明电机通道的测量模型该升级了（见 §8.7）。

## 7.5 仿真环境 2（刚性接触 + 随机漂移 β）的 100 段验证

数据: `data/archive/20260919_sim35_backlash_rigid/`（训练 100 段 + 留出 8 段，各 3 s @100 Hz）。
环境实测统计: β0 ∈ [−0.022, +0.030] rad（每段重抽，上限 ±0.3δ）、漂移 ±0.05δ/30 s；
真值 Δ 的观测极差中位 **0.0880** ≈ δ（但小 yaw 段只有 0.001~0.016 ⇒ β 不可观测）；

这不是数值失败，而是**结构不可辨识**：真实接触是"死区内零刚度 + 接触后刚性"，模型只有
"平滑死区 + 有限刚度 + 直通线性项"可用 ⇒ 优化器用 `δ` 变大、`γ` 变大去**近似那个刚性台阶**
（`k·γ` 变成死区内的等效线性刚度），而 `fv_big` 再次被顶到 `fc_big` 的 1.4 倍
（与实机数据同一现象：未建模效应被粘滞项吸收）。**留出集误差仍然全面下降**，
而且闭环表现几乎不受影响（见 7.5.2）—— 说明这套参数对控制够用，但**不要**当成物理真值读。
`Px/Py` 依旧不可辨识（本数据集没有倾角、且两轴分轴激励 ⇒ 耦合项恒为 0），Py 被噪声带到 −0.0215；
拟合这类数据时应 `--freeze-params=2,3`。

| 主结果（在线 β + 估计状态） | **0.945° / 0.187° / 0.543°** | 0.1060 (+21%) | 180 |
| β 用**真值** | 0.997° / 0.177° / 0.546° | **0.0889 (+1.6%)** | 171 |
| 状态用**真值**（`--state-mode=true`） | **0.583° / 0.143° / 0.515°** | 0.104 (+19%) | 226 |

⇒ 两条独立的结论:
1. **β 的在线估计误差是 `δ` 被高估的主要来源**（+21% → +1.6%），而拟合残差几乎不变 ——
   模型用"更大的 δ + 更大的 γ"把 β 的偏置吸收掉了。这反过来支持"β 必须在运行期在线估计"
   的设计，也指出**提高电机角估计精度**是离线拿到干净 `δ` 的关键（电机角精度被编码器链路的
   延迟/保持卡住，见 §2.1.1）。
2. **把拟合目标换成真值状态，电机通道残差从 0.945° 降到 0.583°** ⇒ 其中约 0.36° 来自
   "电机角估计误差"（它同时在**拟合目标**和**每段初值**里）。剩下的 **0.58° 是模型自身的结构
   误差**：平滑死区（有限 k + 直通项 γ）无法完全表达"死区内零刚度 + 接触后刚性"这个台阶
   —— 这也是 `k` 被顶到 226、`γ` 被顶到 0.085 的原因。
   注意这个 0.58° 是**电机通道**的；真正决定瞄准的**云台通道只有 0.14°**。

## 7.6 γ 冻结 + 4× 数据（10000 epoch，**修订版**）

> ⚠ **先纠正 §7.5 的口径**：`collect_sysid.py` 对 `--seed` 是**确定性**的，而"留出集"当时是
> 用同一个默认 seed（42）另跑一次采的 ⇒ **8/8 段与训练集逐位相同**（4 个并行采集进程同样
> 只有 100 条唯一轨迹）。因此 §7.5 里所有标"留出集"的数字**只能当训练集拟合误差看**。
> 参数层面的结论（δ 由 β 误差主导、γ 会膨胀成软弹簧、平面参数随轮数收敛）与闭环评估
> （在 C++ 里跑、与数据集无关）不受影响。
> 现在辨识脚本内置**训练/留出指纹重合检查**（1e-6 量化，兼容 CSV 六位小数），采集脚本的
> `--seed` 帮助也写明"采留出必须换 seed"；本轮开跑前自检
> `训练段数=400 唯一=400 重复=0；留出 32 段中与训练重合=0`。

数据：**400 段训练**（4 个进程 `--seed=101/202/303/404`）+ **32 段真留出**（`--seed=555`）；
四个 10000-epoch 运行各 ~75 min（并行）。归档 `data/archive/20260919_sim35_backlash_rigid/fit4x/`。

### 7.6.1 真留出集开环 RMSE（窗口 0.1 s；角度 °）

| 运行 | 电机 | 云台 | 小 yaw | 整段 3 s 开环 |
|---|---|---|---|---|
| 初值（头文件那组） | 1.323 | 0.287 | 0.914 | — |
| **A400** γ冻结 0.002 / 400 段 | **1.285** | 0.198 | 0.161 | 3.99 / 3.37 / 1.32 |

1. **γ 冻结几乎不损失精度**（云台/小 yaw 差 4~5%，电机通道完全一样）；

|---|---|---|---|

### 7.6.3 闭环（刚性被控对象 + 随机漂移 β，plant seed 7）

|---|---|---|---|

## 8. 待办（按优先级）

1. **实机采一轮数据**（新格式全量列），用 3-DOF 拟合把 k/c/J_motor/电机摩擦/δ 从占位变实测；
2. 实机验证"模型内建背隙"是否真的消掉抖动；若仍有，先查 k/c 与 δ 的量级；
3. `r_big_torque` / `rd_big_rate` 在新模型下重调；
4. 底盘**转动**工况（机器人自转/机动）下的 θ_p 精度与 MPC 表现（本文 §2.2 的补偿只保证一阶）；
5. 若把 k 标到 >6755 N·m/rad，同步提高 `substeps` 并复核 MPC 求解耗时（当前 3-DOF 下
   平均 1.3–2.2 ms、最大 5.1 ms @10 ms 周期）；
6. **无倾角数据里 `Px/Py` 会被噪声带走**（两轴"分轴激励"⇒ 从不同时动 ⇒ 耦合项
   `μ·θ̇p·θ̇s` 等全为 0，P 没有可观测量）⇒ 拟合时建议 `--freeze-params=2,3`
   或 `--p-constraint=zero`，要定 P 必须补固定 ~10° 倾角的数据（`--tilted`）；
7. 若要把电机通道的拟合精度再提一档：损失里对 `θ_motor` 改用**原始列
   `theta_big_motor_meas` + 链路时延模型**（预测 = θ_motor_sim(t − `big_enc_age`)），
   把估计器的外推误差从目标里去掉。
