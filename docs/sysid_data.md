# 系统辨识数据格式与采集协议（`python/scripts/collect_sysid.py`）

本文件说明**双级 yaw 云台系统辨识数据**是怎么采的、采成什么样、以及拟合时该怎么用。

- 采集脚本: `python/scripts/collect_sysid.py`
- 输出目录: `data/sysid/`（`--out` 可改）
- ★ **仿真环境 2（`--sim-rigid`，仅用于采集测试数据）**: 背隙"接触面完全刚性 + 死区完全自由" +
  β 每条数据随机 + 微弱漂移；实现与动机见 `docs/backlash_model.md` §2.4。它额外写出
  `backlash_center` / `backlash_beta_true` / `theta_true_*` / `dtheta_true_*` 共 8 列
  （实机这 8 列恒 0 = "未知"）。
- 被辨识模型: `include/tcbs/mpc/planar_yaw_model.h`
  - **平面 2-DOF 子块** 8 参: `Jbig_eff, Js, Px, Py, fc_big, fv_big, fc_small, fv_small`
  - ★ **大 yaw 背隙 / 电机侧** 8 参: `backlash_delta, backlash_k, backlash_c, backlash_through,
    Jmotor, fc_motor, fv_motor, backlash_beta`（3-DOF 整机模型，见 `docs/backlash_model.md`）
  - ⇒ 辨识需要 `theta_big_motor`（电机侧）**与** `theta_big_platform`（云台侧）**两列**；
    12 列老数据没有云台侧列，会被辨识脚本跳过并提示重采。

## 1. 采集协议（为什么这么采）

### 1.1 一句话

**分轴激励**: 每段只激励**一个**关节（driven），另一个关节（held）由 PID 闭环守在**随机固定位置**；
激励信号 = **提前录制的目标序列**（`data/targets/*.npz`）+ 数据增强 → 轨迹规划器平滑 →
**上位机 PID 以"仅力矩模式"下发**。**不使用**正弦/傅里叶等固定激励。

### 1.2 四个关键决定及其理由

| 决定 | 理由 |
|---|---|
| **不用固定激励，用录制序列 + 增强** | 待辨识模型里的摩擦是 `fc·tanh(λθ̇)+fv·θ̇`、耦合是 `M11/M12/μ(θ_s)`，都要求在**整个工作范围**上连续变化。单一正弦只激励一条窄带（固定频率/幅值），库仑段与换向段几乎没有数据。录制序列来自真实跟踪工况 ⇒ **工况相符**；随机截取/缩放/偏置 ⇒ 多样化 |
| **分轴采集（driven/held）** | 两轴通过 `M12 = J_s + d·Q(θ_s)` 强耦合。两轴同时被同一激励源驱动会让回归矩阵列相关、8 参最小二乘病态。分轴后"被激励轴 τ↔θ↔θ̇"这条主链干净可辨 |
| **held 轴由 PID 守位，且其力矩也要记录** | 保持轴要顶住被激励轴传来的惯性/离心/科氏扰动力矩才能不动，因此 **`tau_*(held)` 本身就是耦合项的观测量**（含 `M12·θ̈` 等信息），是辨识耦合与惯量的关键通道 |
| **held 目标位置随机化** | `M12`、`μ=∂M11/∂θ_s`、重力项 `G_s=Q_x g_y − Q_y g_x` 都是 **θ_s 的函数**；只在单一 θ_s 上采数据 → `Px/Py` 与 `μ` 不可辨 |

### 1.3 一段采集的时序

```
段开始
 ├─ 读当前状态（温度、平台方位角、小 yaw 角）
 ├─ [可选] --tilted: 打印显著提示，要求把底盘以固定倾角静置
 │        （--tilt-rolling 时先留 10 s 让操作者把倾角调到本段槽位，期间两轴闭环守位）
 ├─ 构造本段参考: driven 轴 = 增强后的录制序列；held 轴 = 常量目标
 ├─ 到位: 两个 PID 同时把 driven 轴拉到参考首值、held 轴拉到 held 目标，稳定 ~2 s
 │        （两轴都要"到位并稳定"，否则段内会混入未记录的阶跃扰动；
 │          移动参考由**轨迹规划器整形**而不是阶跃 —— 阶跃会让 PID 饱和过冲）
 ├─ 采样: 300 点 @100 Hz（3.00 s），每点
 │        忙等到绝对时间点 → 读 est/mcu → 安全判定 → 两轴 PID → 力矩变化限幅
 │        → 仅力矩模式(mode=0)下发 → 记录（含 gravity_ax/gravity_ay）
 └─ 段尾: 主动回到**行程中心**保持（当前行程 ±35° ⇒ 0°；大 yaw 保持当前平台方位角）
          * 只在**程序退出**时才连发零力矩（规格要求）
```

- 选轴: **偶数段（段号 0、2、4…）驱动大 yaw（`axis=0`），奇数段（1、3、5…）驱动小 yaw（`axis=1`）**。
- ★ **前置条件**: 小 yaw 的零点必须先在 `tcbs_test_serial` 里读出并写回 `recv_small_yaw_offset`
  （力矩恒 0、人工把 yaw 摆到机械零点、读它打印的 `yaw_small_angle`，取负即为 offset；
  `send_small_yaw_offset` 取相反符号）；
  **标定之前不得用绝对角指挥小 yaw**（`±35°` 这套限位是以标定后的零点为基准的）。
- 采样时刻用 `time.perf_counter_ns()` **忙等绝对时间点**（抖动 ~µs 级）；`time.sleep()` 的毫秒抖动会让 dt 不准。

### 1.4 硬件侧约定

- 只使用**低层** `torque_controller.TcbsRobotCommunication`（`get_latest_data` / `get_estimate` / `send_to_mcu`），
  不用高层 MPC 控制器 —— 采集必须自己独占力矩通道。
- 下发协议 `include/tcbs/communication/Protocol.hpp`（v0x03）:
  `yaw_big_mode = 0`、`yaw_small_mode = 0`（**0 = 仅力矩**），`pitch_target_angle = 0`（pitch 固定 0，本项目不用它标定），
  `auto_aim_enable = 1`，`fire = 0`。`yaw_*_target_angle/velocity` 在 mode 0 下电控**不使用**，
  仍按"关节角语义"填上当前意图（大 yaw 多圈连续、小 yaw 相对角）仅供电控侧限位/日志参考。
- 反馈:
  - 大 yaw → `est.platform_azimuth`（大 yaw 上 IMU 直测的**平台世界方位角**，实时无延迟，多圈解卷绕）；
  - 小 yaw → `est.small_joint_angle`（编码器，实时可信）；
  - 重力外生量 → `est.gravity_a[0..1]`（A 系平面分量，逐样本记录进 `gravity_ax/gravity_ay`，见 §6.4）。
- 误差按 `e = wrap(目标 − 反馈)` 计算（`math.remainder(·, 2π)`）。

## 2. 文件与命名

```
data/sysid/
├── sysid_big_20260914_181434_00.npz      # 段 0：driven = 大 yaw
├── sysid_small_20260914_181447_01.npz    # 段 1：driven = 小 yaw
└── sysid_small_20260914_181447_01_hold.npz   # 该段前面的静止保持段（--record-hold，默认开）
```

`sysid_<tag>_<时间戳>_<序号>[<后缀>].npz`（★ **默认只写 npz**；`--save-csv` 才额外写一份
同名 `.csv`，仅供人眼看/老脚本用 —— npz 的列是 csv 的**超集**，辨识脚本只读 npz）

| 字段 | 含义 |
|---|---|
| `tag` | 默认按 `axis` 自动取 `big` / `small`；`--tag=exp1` 可覆盖成自定义实验标签 |
| `时间戳` | 本地时间 `YYYYmmdd_HHMMSS`（同名冲突时自动追加 `_1`、`_2`…） |
| `序号` | 段序号（2 位，从 `00` 开始，等于 `--segments` 里的逻辑段号） |
| `后缀` | 空 = 正常采样段（300 点 @100 Hz）；**`_hold` = 静止保持段**（见下） |

#### `_hold`（静止保持段）—— 默认开启

每个采样段在"到位等待"期间（固定 `--settle-sec`，默认 5 s；**稳定判据已删除**），两轴都在做**大角度阶跃**（从当前位姿 → 本段目标，
由轨迹规划器整形）。这段数据同样逐样本落盘（列与采样段**完全一致**、`t` 从 0 连续到保持结束），
**并且一并参与辨识** —— 它正好补上采样轨迹里稀缺的"大幅阶跃"激励。

- 控制开关: `--record-hold` / `--no-record-hold`（**默认开**）；
- **跳过最开始的第一次**（`序号 == 00` 的那次）: 那一拍的起始位姿是任意的（人工摆放/上电瞬态），
  不是一个有意义的受控阶跃；
- 时长固定 = `--settle-sec`（默认 **5 s** = 500 点 @100 Hz；原来还要再加"≥3 s~不限 的稳定等待"，那段判据已按用户要求删除）；
- 保持结束时**立即落盘**（在采样之前）⇒ 采样阶段即使过热重采/中止，这份数据也已经保住；
- 典型幅度（仿真）: 大 yaw 16°、小 yaw 8° 的阶跃，`max|τ| ≈ 0.6 N·m`（两轴都在出力，
  这也是它与采样段的区别: 采样段里 held 轴几乎不出力）。

## 3. CSV 格式（**列头固定**）

```
t,theta_big,theta_small,dtheta_big,dtheta_small,tau_big,tau_small,axis,held_target,mcu2_seq,gravity_ax,gravity_ay
```

前 10 列是采集的核心列；**末尾两列 `gravity_ax,gravity_ay` 是"静态倾斜段"新增的重力列**
（追加在最后，保证按列名取列的读取器继续工作，见 §6.4）。

| # | 列名 | 单位 | 来源 | 说明 |
|---|---|---|---|---|
| 1 | `t` | s | `time.perf_counter_ns()` 差值 | 段内时间，从 0 开始（第一行 ≈ 几个 µs，非精确 0） |
| 2 | `theta_big` | rad | `est.big_joint_angle` | **大 yaw 关节角**（延迟补偿估计；原始编码器值带不确定延迟，用 IMU 角速度做一阶外推补偿到当前时刻） |
| 3 | `theta_small` | rad | `est.small_joint_angle` | **小 yaw 关节角**（相对大 yaw，编码器，实时可信） |
| 4 | `dtheta_big` | rad/s | `est.big_joint_rate` | 大 yaw 关节角速度估计 |
| 5 | `dtheta_small` | rad/s | `est.small_joint_rate` | 小 yaw 关节角速度 |
| 6 | `tau_big` | N·m | 采集脚本 | 大 yaw **限幅后真正下发**的力矩（PID 输出 ±1.0 → 力矩变化限幅 0.1 N·m/步） |
| 7 | `tau_small` | N·m | 采集脚本 | 小 yaw 限幅后真正下发的力矩 |
| 8 | `axis` | — | — | **0 = 大 yaw 被激励**，**1 = 小 yaw 被激励**（段内恒定） |
| 9 | `held_target` | rad | — | **保持轴**的目标角，段内恒定；`axis=0` 时它是**小 yaw 关节角**目标，`axis=1` 时它是**大 yaw 平台方位角**目标 |
| 10 | `mcu2_seq` | — | `mcu.mcu2_seq` | MCU2 新样本序号（大 yaw 与底盘 IMU 同源、共用）。**序号变化 = 大 yaw 值刷新了一次**，可用于识别链路更新率/延迟 |
| 11 | `gravity_ax` | m/s² | `est.gravity_a[0]` | 重力在 **A 系（大 yaw 转子系）** 的 x 分量。**水平静置 ≈ 0**；`--tilted` 倾斜静置时 ≠ 0 |
| 12 | `gravity_ay` | m/s² | `est.gravity_a[1]` | 重力在 A 系的 y 分量（同上） |

- 一段文件 **300 行**（默认 `--duration-sec=3.0`、100 Hz）。行数 = `round(duration_sec × 100)`。
- 数值格式: `t` 保留 4 位小数，其余浮点 6 位小数；`axis`/`mcu2_seq` 是整数。
- 第 11/12 列在**水平采集时全为 0**（此时下游等价于"水平假设"，见 §9）；底盘数据与 `big_enc_age` 只写进 npz，见下节。

## 4. NPZ 格式

`np.load(path)` 后可读到的键如下（全部是 `numpy` 标量/数组）。

### 4.1 与 CSV 逐列对应的时段数组（长度 = 段点数）

| 键 | dtype | 对应 CSV 列 |
|---|---|---|
| `t` | float64 | `t` |
| `theta_big` | float64 | `theta_big` |
| `theta_small` | float64 | `theta_small` |
| `dtheta_big` | float64 | `dtheta_big` |
| `dtheta_small` | float64 | `dtheta_small` |
| `tau_big` | float64 | `tau_big` |
| `tau_small` | float64 | `tau_small` |
| `mcu2_seq` | int64 | `mcu2_seq` |
| `gravity_ax` | float64 | `gravity_ax` |
| `gravity_ay` | float64 | `gravity_ay` |

> `axis` 与 `held_target` 在段内是常量，npz 里按**标量**保存（见 4.3），CSV 里按每行一列写出 —— 两者信息等价。
> `gravity_ax`/`gravity_ay` 是**逐样本**数组，与 CSV 的最后两列完全一致（水平采集时全 0）。

### 4.2 附加时段数组（记录用；`gravity_*` 例外 —— 供拟合使用）

| 键 | 单位 | 来源 | 说明 |
|---|---|---|---|
| `backlash_center` | rad | `est.backlash_center` | ★ **背隙死区中心 β 的在线值**（滑动 min/max，只用刚刷新的样本更新，见 `docs/backlash_model.md` §2.1）。3-DOF 辨识把它当**逐样本外生量**（= 运行期 MPC 拿到的就是它） |
| `backlash_beta_true` | rad | 仿真真值 | ★ 仅 `--sim-rigid` 非 0；实机恒 0。用于诊断在线估计的精度 / `--beta-mode=true` 上限对照 |
| `theta_true_motor` / `_platform` / `_small` | rad | 仿真真值 | ★ 仅 dry-run 非 0。真值状态: ① 量化"电机侧延时补偿估计"的误差；② `--state-mode=true` 上限对照 |
| `dtheta_true_motor` / `_platform` / `_small` | rad/s | 仿真真值 | 同上（角速度） |
| `chassis_yaw` | rad | `est.chassis_azimuth` | 底盘方位角估计（来自经 MCU1↔MCU2 链路的底盘 IMU，零阶保持、带延迟） |
| `chassis_omega` | rad/s | `est.chassis_yaw_rate` | 底盘 yaw 角速度（同上） |
| `big_enc_age` | s | `est.big_enc_age` | 大 yaw 值年龄（上位机计时）。**年龄大 → 该时刻 `theta_big` 的外推补偿更不可信**，可用于给样本降权/剔除 |
| `target_big` | rad | 采集脚本 | 该步下发的**大 yaw 目标**（平台方位角语义；held 轴为常量） |
| `target_small` | rad | 采集脚本 | 该步下发的**小 yaw 目标**（关节角语义；held 轴为常量） |

## 5. 采集参数（固定值）

| 项 | 值 | 说明 |
|---|---|---|
| 采样率 | **100 Hz**（固定） | `--rate` 传更高会被拒绝并警告，仍用 100 Hz |
| 段长 | **300 点 / 3.00 s** | `--duration-sec` 可改（非 300 会警告） |
| 上位机 PID | `kp=5.0, ki=0.0, kd=0.2`（`PID_KP/KI/KD`） + **误差死区 3°**（`PID_DEADBAND_DEG`，`--pid-deadband-deg` 可改；死区内 P/D 按 0 算、积分冻结） | 位置式 + 条件积分抗饱和，输出限幅 **±1.0 N·m**；死区见 `collect_sysid.py::PidController` |
| 力矩变化限幅 | **0.1 N·m/步**（每轴独立） | 保护减速器；记录的是限幅**之后**的值 |
| 到位等待 | **5.0 s**（`SETTLE_SEC` / `--settle-sec`），**单段、固定时长、不判稳定性**（稳定判据已按用户要求删除，2026-09-20） | driven 与 held 两轴同时 PID 到位；走完直接采样 |
| 小 yaw 硬限位（机械行程） | **[−35°, +35°]** | 电控侧也按它限位；`SMALL_TRAVEL_MIN/MAX`（2026-09-21 由 ±30° 放宽，给超调留 5°） |
| 小 yaw **软限位** | **[−30°, +30°]** | **±30° 外才算软限位**：越界只告警（不中止）；距软限位 < 3° 也提示；`SMALL_SOFT_MIN/MAX` |
| 小 yaw 中止阈值（上位机） | **同硬限位 ±35°**（触及即中止本段、数据不保存、回中心） | `SMALL_ABORT_MIN/MAX` |
| 小 yaw 参考包络 | **[−30°, +30°]** | ★ = **软限位**（`SMALL_TRACK_MARGIN = 0°`）；激励参考/到位目标/held 目标都用它 ⇒ 参考可摆到 ±30°，超调落在软限位(30°)~硬限位(35°) 的 5° 里 |
| 小 yaw 行程中心 | **0°** | = (min+max)/2；式子不硬编码 0 ⇒ 非对称行程也自动正确（见 §6.2） |
| 过温阈值 | **55 ℃**（`--max-temp`） | 超过则零力矩降温等待（上限 600 s），恢复后重采该段 |
| 参考规划器（细化 1000 子步/周期） | 大 yaw: `v≤8 rad/s, a≤30 rad/s², j≤800 rad/s³`；小 yaw: `v≤3, a≤15, j≤400` | `TrajectoryPlanner` + `StepRefinementWrapper`；**到位移动与激励参考都走它**（避免阶跃过冲） |
| 静态倾斜段 | `--tilted` 默认**关闭**；`--tilt-rolling` 隐含开启 | 只提示静置姿态 + 记录 `gravity_ax/ay` + 元数据 `tilted=1`。**不做倾角补偿、不改变激励方式、底盘仍静止**（见 §6.4） |

## 6. 参考序列（激励）的构造

### 6.1 通用增强流程（driven 轴）

```
随机选录制文件 → 随机截取 300 点（挑选峰峰值 ≥ 11° 的窗口，丢掉整段静止的平段）
 → np.unwrap 连续化（录制的是绝对角，可能带 ±2π 卷绕）
 → 去直流 + 归一化 → 乘随机幅值（上限 × U(0.6,1) × U(0.5,1)，形状不变、绝不截断）
 → TrajectoryPlanner + StepRefinementWrapper 平滑（限制 v/a/j，得到"跟得住"的参考）
 → **校验平滑后的幅值** ≥ 14°；不够就放大输入重试，仍不够就换窗口（见下）
 → 叠加随机中心
```

* **为什么要平滑**: 录制序列含真实换向与跳变，直接当参考会让 PID 长期饱和打滑（力矩恒为 ±1，回归矩阵近乎常数）。
  平滑后参考在执行器能力范围内，力矩随工况连续变化，辨识才有信息。
* **为什么随机中心**: 大 yaw 取"**现有平台方位角 ±30°**"内随机（多圈自由，取现有角度附近）；
  小 yaw 在带内随机（见下）。
* **为什么必须校验"平滑之后"的幅值**: 录制片段里有一批 **"尖刺型"窗口**（相邻点跳变 1~2 rad），
  轨迹规划器会把它们抹平成一条几乎不动的直线 —— 只看输入幅值会以为这段有激励，实际采到的是一段静止数据
  （自检时真的出现过 3° 的段）。因此平滑后幅值 < **14°** 就放大输入重试，仍不行就换窗口。
* 平滑后叠加常量不影响规划器行为（`step()` 只看 `target − p`，平移不变）。

### 6.2 小 yaw 的行程规则（**对称**: 硬限位 ±35° / 软限位与参考包络 ±30°）

**机械行程 min = −35°、max = +35°**（2026-09-21 由 ±30° 放宽）；**软限位从 ±30° 开始**，
**参考包络 = 软限位 = ±30°**（不再留跟踪余量）。四档含义:

| 档 | 区间 | 用途 |
|---|---|---|
| ① **硬限位**（机械行程） | **[−30°, +30°]** | 电控侧也按它限位；`SMALL_TRAVEL_MIN/MAX` |
| ② **中止阈值**（上位机） | 同上（触及即中止本段、数据不保存、PID 回中心） | 对应旧版的 ±45° 中止；距界限 < 3° 只告警 |
| ③ **软限位** | **[−30°, +30°]** | 越界只告警（不中止）；距软限位 < 3° 也提示 |
| ④ **参考包络** | **[−30°, +30°]**（= 软限位） | 激励参考、到位目标、held 保持目标都用它 |

**中心是 0°**（`SMALL_CENTER_RAD = (min+max)/2`；当前行程对称）。回中心/段尾保持/
每次测量的初始条件都用它 —— 式子写成 `(min+max)/2` 而不是硬编码 0，
以后改成非对称行程（例如 [−20°, +25°]）会自动跟着走。

**所有"±band"的写法都改成区间运算**（对称/非对称行程都正确）:

1. 参考半幅夹到 **≤ 包络半宽 30°**，实际半幅 7°~30°
   （下限 `MIN_EXCITE_AMP_SMALL` = 7° 兜底: 小 yaw 行程比大 yaw 窄，下限不能沿用大 yaw 的 14°）；
2. 中心从**可行中心区间** **`[env_min + 半幅, env_max − 半幅]`** 内随机取
   （`random_center_for()`；非对称区间里"±(band−半幅)"的写法会算错，不再使用）；
3. **若仍超出包络 → 整体等比缩放 + 平移到包络内**（`fit_into_interval()`: 先按区间宽度缩放，
   再把缩放后序列的中点对齐到区间中点，最后数值兜底）。**保留轨迹形状，绝不截断**；
4. 中止判定改成 `θ > max` **或** `θ < min`（两个阈值不再同号对称）。

> `axis=1`（driven = 小 yaw）时，`held`（大 yaw）目标在**现有平台方位角 ±π 内随机**（大 yaw 可多圈连续，无需限幅）。
> `axis=0`（driven = 大 yaw）时，`held`（小 yaw）目标在**参考包络内**随机，但收进 **0.7 倍**
> ⇒ **行程中心 ± 0.7×包络半宽 = ±15.4°**（⊂ 包络）。收窄的理由: 大 yaw 摆动会通过 `M12` 给小 yaw
> 注入扰动力矩（可达 ~0.3 N·m），PID 顶回来需要 ~10° 的瞬时偏差，收窄才有余量不触碰中止阈值。
> 见脚本常量 `HELD_SMALL_MAX`。

### 6.3 到位移动也要整形（踩过的坑）

到位阶段若把目标直接给成**阶跃**（"当前 +15° → 目标 −31°"），PID 会一路饱和到限幅、靠 kd 与输出限幅刹车，
**中途过冲**（仿真实测冲出包络、直接触发中止保护、整段作废）。因此到位阶段的参考也交给轨迹规划器整形
（`homing_sequence()`: 先给"当前值 + 目标值台阶"，让规划器输出 jerk 受限、提前刹车的移动）。
这不改变 PID 参数，也不改变数据格式，只是让"到位"过程本身安全可控。

### 6.4 静态倾斜段（`--tilted`）: **固定一个倾角贯穿全程即可**

**为什么倾斜有用**: 水平时 `gravity_a` 的平面分量为 0 ⇒ 重力项 `G_s = Qx·gy − Qy·gx` 恒为 0，
`Px/Py` 只能靠 `M11/M12/μ` 里的 `d·Q = d·R(θ_s)·P` 被间接观测（`d` 很小）⇒ 与惯量参数高度共线
（自检 corr ≈ −0.93，`σ_P` 大 ~40 倍）。倾斜后这个通道被打开。

**★ 关键结论: 不需要"多倾角"，也不需要 `--tilt-rolling`。** 固定一个底盘倾角 φ 时，
**A 系（大 yaw 转子系）里的重力平面分量是

```
g_A(t) = Rz(−θ_b(t)) · (g·sinφ, 0)
```

——它随大 yaw 方位角 θ_b 一起旋转**。所以:

* **各段的 held 大 yaw 方位角铺得开**（我们本来就随机 ±π），**再加上大 yaw 被激励的段**，
  同一个物理倾角在 A 系里就等效于**多个不同方向的重力** —— 这正是辨识 `P` 需要的激励；
* ⇒ **一个固定倾角贯穿全程即可**（`--tilted` 就是这个模式，不轮换）；
  `--tilt-rolling` 只是可选项、**不必要**（往返搬动底盘反而引入装配/回差风险）。

**建议**: `φ ≈ 10°~15°`（`|g_A| = g·sinφ ≈ 1.7~2.5 m/s²`）。
**关键判据是拟合输出的 `|Px|/σ`、`|Py|/σ`**（目标 **≥3**）: 达不到就加大 φ 或加段数。

**另外三条**: **`m_u_known·(d×g)` 项只有倾斜时才起作用**；沿 yaw 轴的重力分量对**平面模型无影响**；
**倾斜不改变激励设计**（大小 yaw 照常分轴激励、held/驱动关系与限位规则都不变）。

**副作用与注意**:

1. 倾斜会给小 yaw 一个重力矩 `G_s(θ_s) = |P|·|g_A|·sin(θ_s + ·)`，本项目量级
   `0.01 kg·m × 1.7 m/s² ≈ 0.017 N·m`，**远小于小 yaw 的力矩能力**（PID 轻松顶住），不构成问题；
2. **小 yaw 零点的读取建议在"放平"状态下做**（人工摆放的基准若本身与
   姿态无关则无妨，但放平更可复现）;
3. 固定倾角下**其余参数（惯量/摩擦）的辨识不受影响**。

**★ 可选开关 `--held-big-stratified`（默认关）**: 让小 yaw 被激励的段里，held 大 yaw 方位角
**按下标均匀铺满 ±π**（例如 4 个小 yaw 段 ⇒ 偏移 −135°/−45°/+45°/+135°），而不是纯随机 ——
这样同一个固定倾角下 `g_A` 的方向覆盖更均匀，`P` 的条件数更好。开启后实际取值会写进
npz（`held_big_stratified / held_strat_index / held_strat_count / held_strat_offset`）
并在终端逐段打印。

> 实现细节见 `collect_sysid.py` §五；脚本只**提示**静置姿态并**逐样本记录** `gravity_ax/ay`
> （CSV 末两列 + npz 数组），**不做任何倾角补偿**；水平采集时这两列恒为 0，
> 下游等价于"水平假设"。

## 7. 安全策略

| 触发 | 动作 |
|---|---|
| 小 yaw θ 超出**硬限位 [−30°, +30°]** | **立即中止本段**（数据**不保存**，避免污染） → PID 回**行程中心**（当前 0°；大 yaw 保持当前方位角）；距界限 < 3° 只打印告警 |
| 电机温度 ≥ `--max-temp` | 中止本段 → 100 Hz 零力矩保温等待，降到 `max_temp − 5 ℃` 后**重采同一段号**；600 s 未降下来则退出 |
| Ctrl+C | 立即停止激励 → 按 0.1 N·m/步斜坡把两轴力矩压到 0 → **连发 20 帧零力矩** → 关闭句柄 |
| 正常结束 / 异常退出 | 同样经过 `safe_shutdown()`：斜坡归零 + 连发零力矩 |
| 段尾 | 主动回到**行程中心**（当前 0°）保持（大 yaw 保持）——比"撒手零力矩"安全: 段末残余角速度会通过耦合把另一轴推走 |

段号 `0…segments−1` 与文件名序号一致；被中止的段会跳过该段号（不重排）。

## 8. 无硬件自检（`--dry-run`）与仿真环境 2（`--sim-rigid`）

```bash
python3 python/scripts/collect_sysid.py --dry-run --segments=1
```

- 用**内置仿真**代替串口: 被控对象直接实现 `include/tcbs/mpc/planar_yaw_model.h` 的同一组方程
  （`M(θ_s)`、`μ`、科氏/离心、重力、`fc·tanh(λθ̇)+fv·θ̇`，参数取该头的默认值），
  **λ = 100**（模拟真实库仑摩擦的陡峭软符号）、**积分步长 0.05 ms**（RK4，200 子步/控制周期；
  摩擦模态时间常数 ~2 ms ≫ 0.05 ms，数值稳定）。

  `mcu2_seq` / `big_enc_age`（模拟 ~10 Hz、间隔 80~120 ms 不规则、值被保持的 MCU2 链路）。
- 因此 **dry-run 与实机走同一条采集代码路径**，可用来验证脚本逻辑、时序与输出格式；
  生成的 npz 列（以及 --save-csv 时的 csv 列头）、行数与实机完全一致。

## 9. 拟合时怎么用

**用于拟合的列**: `t, theta_big, theta_small, dtheta_big, dtheta_small, tau_big, tau_small`
（`axis` 用来分轴建回归矩阵；`held_target` 用于分组统计；**`gravity_ax/gravity_ay` 有非零值时启用重力项**）。

1. **按轴分文件**读入: `axis=0` 的文件里，大 yaw 是被激励轴、小 yaw 是保持轴（反之亦然）。
2. 每个采样时刻的回归行按 `planar_yaw_model.h::regressor` 组装:
   被激励轴那一行信息最丰富；**保持轴那一行别丢** —— 它含有 `M12·θ̈ + μ` 等耦合信息（§1.2）。
3. `theta_big` 是**延迟补偿估计**，`big_enc_age` 给出该时刻的年龄: 年龄越大，补偿外推越不可信，
   建议在加权最小二乘里按年龄降权，或剔除 `big_enc_age` 过大的样本。
4. `chassis_yaw` / `chassis_omega` 只作诊断（模型里的 `base_omega`/`base_alpha` 外生量）；
   采集时底盘静止（含倾斜段），因此拟合里取 0 即可。
5. `dt = 0.01`（`dtheta_*` 由估计器给出，不要自己差分 `theta_*` 求速度 —— 编码器噪声会被放大）。
6. 力矩是**限幅后的下发值**，与实际作用力矩一致（力矩变化限幅 0.1 N·m/步会削掉高频成分，
   拟合时应把它当作真实激励，而不是当作理想 PID 输出）。
7. **重力列怎么用**（`gravity_ax` / `gravity_ay`，m/s²，A 系平面分量）:
   - 列**全为 0** ⇒ 数据是水平静置采的，代入 `e.gravity_a = (0,0)` 即可 —— 与本文档之前的版本**完全等价**，
     此时 `Px/Py` 只能靠 `d·Q` 弱观测（共线，见 §6.4），建议只把结果当粗值；
   - 列**有非零值** ⇒ 必须**逐样本**代入（不要用段平均值），因为 A 系里的 `(gx, gy)` 会随
     `θ_big`（平台方位角）的变化而旋转 —— 这正是倾斜段给 `P` 带来的独立观测通道；
   - 读取器按列名匹配（含 `g_a_x` 等别名）即可识别这两列，
     也可以用 `--gravity-a=gx,gy` / `--tilt-deg=<deg>` 手工指定（后者只适合合成数据自检）；
   - 元数据 `tilted=1` 标记该段来自倾斜静置；`tilt_slot` 指示 `--tilt-rolling` 下的倾角槽位，
     可用于分组检查"不同倾角是否都采到"。
8. **建议的采集组合**: 先按原方式采若干水平段（评估基线/复现旧结果），再用 `--tilt-rolling`
   采若干倾斜段（+10° / 0° / −10° 轮换，让 `(gx, gy)` 在 A 系里取到不同方向），
   最后把两类 CSV 一起喂给辨识工具（重力列会自然地把两类数据区分开）。
