# 双级 yaw 云台的平面二维模型（8 个待辨识参数）

> 本文件说明 `include/tcbs/mpc/planar_yaw_model.h` 里那套方程的来源、包含什么、不包含什么、
> 哪些参数需要辨识、以及如何验证。**完整推导写在头文件注释里**，本文件给出工程视角的说明。

---

## 1. 化简前提（由用户确认）

| # | 前提 | 后果 |
|---|---|---|
| 1 | 两 yaw 轴平行；小 yaw 轴相对大 yaw 轴只有**平面偏置 `d`**（几何可实测） | 姿态链可合并为 `Rz(θ_b+θ_s)`；力矩层面两轴仍通过 `d` 强耦合 |
| 2 | **大 yaw 转轴不位移** | 底盘绕关节轴转动时 O1 不动 ⇒ 底盘耦合项可用解析式写出（见 §4） |
| 3 | 忽略 pitch 转动对上装质心的影响 ⇒ **pitch 不进动力学** | pitch 只作为"下发给电控的目标角"存在；采集时恒为 0 |
| 4 | **质心不单独测量**，用"上装一阶矩" `P = m_u·ρ` 表征 | `m_u` 与 `ρ` 只在乘积中出现；控制上 `P` 已足够 |
| 5 | 大 yaw 侧不含小 yaw 部分的质量/惯量整体并入 `Jbig_eff` | 不再分别标定 `mA/IA_*/mB/rB` 等 |

> 与上一版（40 参三维刚体模型）相比：**参数从 40 个减到 8 个**，且方程对参数**严格线性** ⇒
> 辨识是标准线性最小二乘问题，不再有大规模不可辨识子空间。

## 2. 坐标系与记号

```
底盘 ──[关节1 大yaw θ_b, 轴 = C/A 系 z]── 体 A（大yaw 转子：IMU 平台 + 小yaw 定子）
     ──[关节2 小yaw θ_s, 轴 = 同一 z, 原点 O2 = O1 + d]── 体 B（小yaw 转子 + pitch 定子）
     ──[关节3 pitch θ_p, 轴 = B 系 x, 原点 O3 = O2 + c]── H（头部）
```

### 2.1 坐标系约定（**全仓库统一**，与父工程 `UnifiedAutoAimPipeline` 一致）

| 项 | 约定 |
|---|---|
| 右手性 | 右手系 |
| 三轴含义 | **x = 右、y = 前、z = 上**（重力矢量 = `(0, 0, -g)`，即 −z 向下） |
| 欧拉角 | **ZXY**: `R = Rz(yaw)·Rx(pitch)·Ry(roll)`（先绕 z 转 yaw、再绕 x 转 pitch、再绕 y 转 roll） |
| yaw | 绕 **z** 轴，正方向 = **从上方看逆时针**（x 轴转向 y 轴，即"右→前"） |
| pitch | 绕 **x** 轴，正方向 = **抬头**（y 轴转向 z 轴，即"前→上"） |
| roll | 绕 **y** 轴，正方向 = z 轴转向 x 轴（"从画面看顺时针"） |
| 关节轴 | 两个 yaw 关节都绕各自环节的 **z** 轴；**pitch 关节绕 x 轴**（x 即左右横轴） |
| 视轴/枪管 | 在 head 系 y-z 平面内，**默认沿 +y（前向）**（`Config::bore`，可按装配标定） |
| "世界方位角" | 某环节 **x 轴**的世界方位角: `ψ = atan2(R[1][0], R[0][0])`（世界系里从 +x 逆时针转向 +y）⇒ **方位角 0 = 指向 +x（右）**，正前方（+y）= +90° |
| 重力平面分量 | 一律取 **A 系** 的 `(x, y)` 分量（`gravity_a[0..1]`），见 §5 |

> 注: `platform_azimuth / small_output_azimuth / chassis_azimuth / head_azimuth / los_azimuth`
> 全都是"**x 轴的世界方位角**"这一种定义（LOS 的方位角是对 `bore` 方向取同一度量）；
> 而 `chassis_euler_yaw` / `head_world_yaw` 等是 **ZXY 欧拉角**。两者在该环节相对世界有
> 俯仰/横滚倾斜时**不相等**（差约 `pitch·roll`），本仓库报告的量统一用前者（矩阵精确值）。

- **C 系 / A 系**: z 轴沿两 yaw 关节轴；A 系 = C 系绕 z 转 θ_b（**IMU 就装在 A 系上**）。
- `d = (dx, dy)`：小 yaw 轴相对大 yaw 轴的平面偏置，**实测几何量**。
- `ρ`：上装质心相对小 yaw 轴的位移；`P = m_u·ρ`（待辨识）。
- **`g_A`**：重力在 **A 系**的平面分量。**必须是 A 系而不是 C 系**——原因见 §5。

## 3. 动力学（τ = M(q)·q̈ + h）

设 `Q(θ_s) ≜ R(θ_s)·P`，`μ ≜ ∂M11/∂θ_s = 2(dy·Qx − dx·Qy)`：

```
M22 = Js
M12 = Js + d·Q(θ_s)
M11 = Jbig_eff + Js + 2·d·Q(θ_s)

h_b = μ·θ̇_b·θ̇_s + ½μ·θ̇_s² − G_b + μ·θ̇_s·ω_c + M11·α_c + fric_b + τ_off,b
h_s = −½μ·θ̇_b² − G_s        + (−μ·θ̇_b)·ω_c − ½μ·ω_c² + M12·α_c + fric_s + τ_off,s

G_b = m_u_known·(dx·g_y − dy·g_x) + (Qx·g_y − Qy·g_x)      ← 重力（底盘水平时 = 0）
G_s =                                (Qx·g_y − Qy·g_x)
fric_k = fc_k·tanh(λ·θ̇_k) + fv_k·θ̇_k                      （λ 固定 10，不辨识）
```

**物理含义（便于交叉检查）**：

| 项 | 含义 |
|---|---|
| `M12 = Js + d·Q(θ_s)` | **小 yaw 转动对大 yaw 的反作用**：`Js·θ̈_s` 是纯反扭力矩；`d·R(θ_s)P·θ̈_s` 是"上装质心偏离小 yaw 轴 ⇒ 需要给 O2 施力 ⇒ 该力对大 yaw 轴的力矩"（质心正好在轴上时 `P=0`，这一项消失 ✓） |
| `−½μθ̇_b²`（h_s） | 大 yaw 快速转动时**把小 yaw 往外甩**的离心力矩（`μ ∝ d×P`） |
| `M11·α_c + μθ̇_sω_c` 等 | 底盘绕关节轴转动的耦合（**完全由 M 及其偏导构成，不需要 m_u 或新参数**） |
| `G_s, G_b` | 底盘倾斜时的重力力矩（水平时为 0） |

`G_b` 里的 `m_u_known·d×g` 一项需要上装质量 `m_u`；**用户不称重 ⇒ 保持 `m_u_known = 0`**，
即该项不建模（水平时它本来就为 0；倾斜时它表现为大 yaw 轴上一个"随倾角变化的恒定负载"，
可由摩擦/积分补偿吸收）。

## 4. 底盘耦合项（为什么不需要额外参数）

系统对关节轴的角动量 `L = ω_c·M11 + Σ_j M_1j·θ̇_j` ⇒ 动能的交叉项为 `N_k = ω_c·M_k1`。
代入拉格朗日方程即得 §3 里那些 `ω_c/α_c` 项——**注意 `α_c` 项不乘 `ω_c`**
（`M_k1·α_c`），且小 yaw 方程里 `+½μθ̇_sω_c` 与 `−Σ_i(∂N_i/∂q_k)θ̇_i` 里的 `−½μθ̇_sω_c`
**正好相消**，只剩 `−μθ̇_bω_c`。这两处都是开发中靠"与独立数值参考比对"抓出来的符号错误，
已在 `tests/test_planar_yaw_model.cpp` 里固化为回归测试。

---

## 5. 重力为什么必须用 A 系（重要）

绕轴的力矩 `τ = ẑ·(r × m·g)` 要求 `r` 与 `g` 表达在**同一个旋转系**里。取 **A 系**时
`r_u^A = d + R(θ_s)ρ` **不含 θ_b**，于是：

1. 公式对 `θ_b` 无关 ⇒ 预测窗内不需要（延迟/带误差的）`θ_b`；
2. `g_A` 可由 IMU **直接**算得：默认构型下 `g_A = R_mount·g_imu`（连 θ_b 都不用）。

若误用 C 系重力（`g_C`），会丢掉"质心随大 yaw 转动使重力矩随 θ_b 变化"的部分 ⇒ 倾斜时出现
系统性偏差。`YawStateEstimator` 输出的 `gravity_a` 就是按此定义的。

## 6. 8 个待辨识参数

| # | 参数 | 含义 | 单位 | 主要由哪段数据定 |
|---|---|---|---|---|
| 0 | `Jbig_eff` | 大 yaw 侧惯量（含 `m_u·|d|²` 平行轴项） | kg·m² | 大 yaw 被激励那段：`τ_b/θ̈_b` |
| 1 | `Js` | 上装绕小 yaw 轴总惯量（含 `m_u|ρ|²`） | kg·m² | 小 yaw 被激励那段：`τ_s/θ̈_s` |
| 2–3 | `Px, Py` | 上装一阶矩 `m_u·ρ` | kg·m | **保持轴**的力矩随驱动轴加速度/角速度的变化（见下） |
| 4–5 | `fc_big, fv_big` | 大 yaw 库仑/粘滞摩擦 | N·m, N·m·s/rad | 大 yaw 段的多速度区间 |
| 6–7 | `fc_small, fv_small` | 小 yaw 库仑/粘滞摩擦 | 同上 | 小 yaw 段的多速度区间 |

**可辨识性要点**：
- `P` 的信息**只出现在"被保持那一轴"的方程里**（它代表"另一轴运动对本轴的耦合反作用"）
  ⇒ 采集时**必须记录两轴的力矩与角/角速度**；
- 小 yaw 段中被保持的大 yaw 力矩里含 `M12(θ_s)·θ̈_s = (Js + d·R(θ_s)P)·θ̈_s`，
  θ_s 在整个行程（`[−25°, +20°]`，可留 8° 余量后约 29° 摆幅）上扫动时
  `d·R(θ_s)P` 随 θ_s 变化 ⇒ 由 `cosθ_s/sinθ_s` 两个分量可分离出 `Px、Py`
  （**所以小 yaw 必须扫开角度，不能只在零位附近小幅晃**）；
- 大 yaw 段中被保持的小 yaw 力矩里的 `−½μθ̇_b²` 再给一组 `d×P` 的约束（交叉验证）；
- `m_u` 与 `ρ` 不可分离（只有乘积 `P` 可辨识）；`J_big` 与 `m_u|d|²` 亦不可分离
  （只有 `Jbig_eff` 可辨识）——**对控制都足够**；
- `d` 是实测几何量，其相对误差会**等比例**传进 `P`。

### 6.1 一个有用的推论: 离心平衡点（可用来标定小 yaw 零位）

令大 yaw 以**恒定角速度 Ω** 旋转（`θ̇_b=Ω`、`θ̈_b=0`）、底盘静止、**小 yaw 完全松手**
（`τ_s=0`）且已静止（`θ̇_s=θ̈_s=0`），水平底盘下由 `h_s` 立刻得到

```
0 = −½·μ(θ_s)·Ω²   ⇒   μ(θ_s*) = 0   ⇒   R(θ_s*)·P ∥ d
```

（稳定解是**径向外侧**那个: 离心力把上装质心甩到大 yaw 轴的最远处；另一侧是不稳定平衡。）

这一点的价值在于 **`θ_s*` 只由机械几何决定**——与编码器零位无关、与任何 IMU 无关，
而且是个**稳定吸引子**（等效刚度 `k = Ω²·|d|·|P|`），所以它可以直接当作小 yaw 编码器的
**绝对零位参考**（工具: `python/scripts/calibrate_small_zero.py`，详见 `docs/calibration.md` §3.5）。

**两个必须记住的推论**:

1. **两类系统误差要用两种不同的平均来消**（都做才干净）:
   - 静摩擦使它停在 `|F_drive| = fc` 处而非 `F_drive = 0` 处，**偏差方向只由"从哪一侧逼近"决定**
     ⇒ 该偏差是 **Ω 的偶函数**（`+Ω`/`−Ω` 停位完全相同），量级 ≈ `fc_small/(Ω²|d||P|)`
     ⇒ 必须**从平衡点两侧交替逼近后取平均**（实测 ±2.4° → 0.000°）；
   - 而**空气阻力**等与 Ω 成正比的耗散（载荷平动速度含 `Ω×r`，投影到小 yaw 轴的广义力含
     `−c·Ω·(d·Q+|Q|²)`）会把整个平衡点平移，且偏移量是 **Ω 的奇函数** ⇒ 只能靠
     **`±Ω` 双向平均**抵消（实测 c=0.5、Ω=40 时 ∓1.136° → 0.000°）；
   - **底盘倾斜**（重力）是 Ω 偶函数、两种平均都消不掉 ⇒ 只能把底盘放水平。
2. **平衡点读数给出 `P` 的方向（但只在"测过平衡点"时成立）**: 平衡条件在任意零点约定下都是
   `R(θ*)·P ∥ d`；若记 `θ*_meas` 为平衡点在**当前零点坐标系**里的读数，则
   `P = |P|·R(−θ*_meas)·d̂`（零点恰在平衡点 ⇒ `Py=0`）。
   ⚠ **本项目的首选零位标定是"人工摆放 + 读编码器"（`--method=manual`）**，
   此时零点与平衡点无关、`θ*_meas` **未知** ⇒ **辨识时必须让 `Px/Py` 自由**，
   或另做一次离心/重力实验测出 `θ*_meas` 再用上面的约束。
   （能测到平衡点时，它确实能缓解 §6 里"水平数据下 `Px/Py` 与惯量共线"的问题。）
3. **转速受限时优先用重力平衡点**: 离心法的刚度 `k=Ω²|d||P|` 正比于 Ω²；大 yaw 若限制在
   "2 s 一圈"（Ω≤π），`k` 小到**推不动小 yaw**（驱动力 `k·Δθ` 顶不过 `fc_small`）。
   改成把底盘**静态倾斜 φ**、让重力分量当"弹簧"（`k_g = |P|·g·sinφ`），只要 `φ > 1.7°`
   就比 Ω=π 的离心法强，φ=90° 时强 33 倍，且没有空气阻力。

## 7. 摩擦模型参数 λ（重要工程约束）

`λ` 决定软符号陡度 `tanh(λω)` 的饱和速度：**要在 |ω| ≈ 1°/s = 0.0175 rad/s 就进入饱和区，
需要 λ ≳ 3/0.0175 ≈ 170** ⇒ 本项目取 **λ = 100**（模型与辨识都用它），
比起早先的 λ=10（过渡带 0.1 rad/s，低速段完全是线性阻尼，根本不像库仑摩擦）更接近真实摩擦。

| 用途 | λ | 说明 |
|---|---|---|
| **辨识/MPC 的模型** | **100** | `ModelParams::frictionLambda = 100`（`planar_yaw_params.h`）；在 |ω| ≳ 1°/s 饱和 |
| **仿真被控对象** | **1e4**（≈sign） | 更陡、更接近真·库仑；积分步长必须 ≤ ~50 µs 防抖（本项目用 20 µs） |

**数值代价（必须知道）**: 摩擦模态的 Jacobian 是 `∂fric/∂ω = fc·λ·sech²(λω)`，
最大值为 `fc·λ`（单位质量意义上还要乘 `M⁻¹`，约 `fc·λ·inv`，本项目 `≈ 360~700 /s`）。
显式 RK4 的稳定上限是 `dt < 2.78/|J_f|`：

- λ=100、`fc≈0.22/0.097`、`J≈0.02~0.05` ⇒ 上限 **≈ 4~8 ms** ⇒ 控制步 `dt=10 ms`
  时**必须用积分子步**：`DualYawMpcConfig::substeps = 4`（有效步长 2.5 ms，实测留 ~2× 余量）；
- λ=1000 ⇒ 上限 **≈ 0.4~0.8 ms** ⇒ 需要 `substeps ≈ 32`，MPC 单次求解从 ~0.9 ms 涨到
  **3~6 ms（最坏 12~20 ms）**，**超过 10 ms 控制周期**（实测见 `docs/sysid_ls_vs_torch.md` §5）；
- 仿真被控对象 λ=1e4 ⇒ 上限 ≈ 57 µs ⇒ 用 20 µs 子步（`tests/test_dual_yaw_mpc.cpp`）。

`recommendedFrictionLambda()` 给出给定 `dt`（**应传有效步长 `dt/substeps`**）下的上限，
`DualYawMpc` 构造时会检查并告警（该检查已改为按子步折算）。

## 9. MPC 与实时性

实测（本机单核；**模型 λ=100、`substeps=4`、plant λ=1e4**）：
`RK4 N=12 max_iter=8` **平均 ~0.85~1.4 ms**、最坏 ~1.8~2.8 ms（周期 10 ms）；
`N=20` 约 3.8 ms；半隐式欧拉 `N=12` 约 0.47 ms（更耗散，RMS 反而略小）。
（早先 `λ=10 / substeps=1` 时是 ~0.6 ms；λ=100 需要 4 个子步 ⇒ 约 1.5~2× 代价。）
非对称行程改造（双侧软限位 + 回中中心）**没有增加求解规模**（残差个数不变）。
λ=1000 需要 `substeps≈32` ⇒ 平均 3~6 ms、最坏 12~20 ms，**超出控制周期**。
车载计算机更慢时按 `loop_fps` 实测调整 `N/max_iter/use_rk4`。

## 10. IMU 安装位置可切换（运行时）

`tcbs::YawStateEstimator::Config::imu_location` 支持两种构型：

| | 默认（`ON_BIG_YAW`，IMU 在大 yaw 转子上） | 备选（`ON_HEAD`，IMU 移到头上） |
|---|---|---|
| 头姿态 | 反解 `R_imu·R_mountᵀ·Rz(θ_s)·Rx(θ_p)` | **IMU 直测** |
| 大 yaw 平台方位角 | **IMU 直测** | 由 `头IMU − 小yaw编码器` 反推（仍是实时可信量） |
| 小 yaw 输出方位角 | `平台方位角 + θ_s`（编码器） | **头 IMU 直测**（pitch 不影响 x 轴方位角） |
| 大 yaw 关节角速度 | `gyro·a_imu − ω_chassis` | `gyro·a_imu(θ_p) − ω_chassis − θ̇_s`（**多减一项小 yaw 编码器角速度**） |
| 重力 `g_A` | `R_mount·g_imu`（不需 θ_b） | `Rz(θ_s)Rx(θ_p)·R_head_mount·g_imu`（不需 θ_b） |
| pitch 标定 | 用 `tcbs_pitch_calibration`（需 IMU 在头上） | 同左（此时头上有 IMU，`imu.euler_pitch` 就是 pitch 关节角） |

**两构型实测对比**（`tests/test_yaw_state_estimator.cpp`，同一真值轨迹与同一 MCU 链路，
`[4]/[5]/[6]` 三个场景；数字为最大误差）:

| 指标 | `ON_BIG_YAW` | `ON_HEAD` |
|---|---|---|
| 平台方位角 | 4.4e-16 rad | 3.8e-3 rad |
| 小 yaw 输出方位角 / LOS / 头欧拉 yaw | 3.7e-3 rad | 4.4e-16 rad |
| `gravity_a` | 3.6e-15 m/s² | 1.2e-2 m/s² |
| 大 yaw **关节角** | 0.0116 rad | 0.0290 rad（2.5×） |
| 大 yaw **关节角速度** | 0.025 rad/s | 0.514 rad/s（**20×**） |
| 值保持链路（3~10 Hz）下的大 yaw 关节角 | 0.0350 rad | 0.1223 rad（≈7°） |

> **结论**: 两种构型下**瞄准真正依赖的量**（世界方位角、重力方向）都精确且不依赖 θ_b；
> 代价全部集中在大 yaw 的**关节量**上（`ON_HEAD` 的 θ̇_b 多了一项来自小 yaw 编码器
> 低通滞后的 0.34 rad/s，外加底盘零阶保持的 0.03 rad/s），而关节量直接进入 MPC 的
> 动力学预测 ⇒ **`ON_HEAD` 只适合临时验证/降级运行，控制质量明显次优**。
> 另: 按"底盘角速度 = 抑制了两关节贡献的陀螺投影"这一既有规范实现的 `base_omega`
> 在 `ON_HEAD` 下会残留 `θ̇_s·ẑ_A + ṗ·x̂`（实测与纯底盘角速度差 2.81 rad/s）——
> 已在 `YawStateEstimator` 注释与测试中标注，未擅自改动语义。

两套反解分支并存、一次编译即可切换，`setConfig()` 可在运行时切换（场景 `[6]` 覆盖）。
