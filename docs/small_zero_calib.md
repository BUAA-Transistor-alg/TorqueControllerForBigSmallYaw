## 0.0 ★★ 三种方法排序（**主路径 = manual**）

用户最终决定: **人工把小 yaw 固定/摆到"准确的零点"那个物理位置，此时读出编码器角度即可**。
离心法（以及重力法）**只是实验**，不是主路径。

| 顺位 | 方法 | 定位 | 说明 |
|---|---|---|---|
| **① 首选（主路径）** | **`--method=manual`** | **零点捕获** | 小 yaw **力矩恒 0**（松手），人工用手/工装摆到零点位置；工具只读 `est.small_joint_angle`，做窗口稳定性判据 + 重复性统计（`--repeats`，每次重新摆放）。**不需要任何标定运动/力**，也不依赖 `P`、不依赖 Ω、不依赖倾角 |
| ② 实验性交叉校核 | `--method=centrifugal` / `gravity` | 验证"人工零点是否合理" | 只能给出"平衡点读数 `θ*_meas`"与 `P` 的方向线索；**Ω≤π 下离心法不可用、重力法强 9.9 倍但仍不够**（见 §8/§10）。它们的结论一律标注为**实验性** |
| ③ 独立交叉校核 | `--probe-travel` | **只用于 scale 校核** | 用低力矩 + 失速检测量出物理行程宽度 W（应 ≈45°）与"零点距两侧各多少"（信息性数字）。**⚠ 不能用来定零点** |

> **⚠ 重要（用户确认）**: `−25°/+20°` 这个非对称分配**本身是从（尚未标定的）电零点估出来的，
> 不是独立机械事实** ⇒ 因此「停止位 − 20°」**不能**用来定零点；`--probe-travel` 只报
> **行程宽度（scale 校核）** 与到两侧的信息性距离，**不再**写成"自洽性判据通过/不通过"。

```bash
# ★ 首选流程（真机）——不需要 --ack-mcu-limits-bypassed（小 yaw 力矩恒 0，与电控限位保护无冲突）
python3 python/scripts/calibrate_small_zero.py --method=manual --repeats=3 \
        --window-sec=1 --manual-tol-deg=0.2 --note="用 3D 打印定位块 + 直尺基准"
# 仿真自检（已知零点 + 人工摆放散布）
python3 python/scripts/calibrate_small_zero.py --sim --method=manual --repeats=3 --manual-tol-deg=0.2
```

## 0. ★ 三条前置条件（违反任何一条都会把数据做成垃圾）

| # | 前置条件 | 为什么 |
|---|---|---|
| **1** | **标定前"绝对角度"不可用 ⇒ 只用相对读数** | 电控送来的小 yaw 编码器 **0 点对应哪个物理位置是未知的**；`[−25°, +20°]` 这套行程限位是**以标定后的 0 点（= 离心平衡点）为基准**定义的。所以标定前既不知道"行程中心 −2.5°"在哪，也不知道"离限位还有多少度"。脚本一律用 **相对当前读数的偏置** `target = mapped_now + δ`（δ 只有几度） |
| **2** | **第一次测量不做任何预置** | 直接从当前位置**松手**（τ=0）→ 大 yaw 加速到 Ω → 稳定 → 等小 yaw 停住 → 读 θ̂₀（未知坐标系里的第一个平衡点估计）。之后每次才用 `θ̂ ± δ` 的相对偏置把起点放到平衡点两侧（交替），**偏置在 Ω 稳定之后才施加** |
| **3** | **标定期间必须临时放宽/旁路电控的小 yaw 限位保护** | 电控的限位/软限位用的是**同一个（错误的）零点**，标定期间它会误判并把小 yaw 力矩清零。真机路径必须显式 `--ack-mcu-limits-bypassed`（否则脚本**拒绝开跑**，退出码 3）。最后防线保留: 低力矩限幅 + 失速检测 + 机械硬限位。**标定出 `Δoffset` 并写入后，恢复 `[−23°, +18°]` 那套目标夹取** |

安全策略因此**全部换成相对量**（绝对守卫在标定前没有意义）:

* **相对起始读数位移预算** `|mapped − mapped0| ≤ --rel-budget-deg`（默认 12°）
* **累计路径预算** `--rel-path-budget-deg`（默认 400°，是"异常振荡"探测器，不是行程守卫）
* **失速检测**（`--stall-sec` 0.8 s / `--stall-deg` 0.15°）: 加了力矩却不动 ⇒
  *完全推不动*判为**撞机械限位/电控清零力矩**（立即中止并**反向退回**）；
  *推得动但到不了目标*是稳态 Ω 下的**弹簧+力平衡点**（正常，继续测）
* **低力矩限幅** `--bias-torque`（默认 **0.25 N·m**，见 §3.4；`0.05 N·m` 在稳态 Ω 下**推不动**）
* **|θ̇_small| 过大立即中止**（`--rate-abort` 默认 8 rad/s）

## 1. 物理原理

平面模型（`include/tcbs/mpc/planar_yaw_model.h`）里小 yaw 的力矩方程:

```
τ_s = M12·θ̈_b + M22·θ̈_s − ½·μ(θ_s)·θ̇_b² − G_s
      + ω_c(½μ θ̇_s − μ θ̇_b) − ½μ ω_c² + M12·α_c + fric_s + τ_drag,s

M11 = Jbig_eff + J_s + 2·d·Q,  M12 = J_s + d·Q,  M22 = J_s
Q(θ_s) = R(θ_s)·P,  μ = ∂M11/∂θ_s = 2(dy·Qx − dx·Qy),  P = m_u·ρ,  d = (dx,dy)
```

前提 ①**大 yaw 恒定 Ω**（θ̇_b = Ω、θ̈_b = 0）②**底盘绕关节轴静止**（ω_c = α_c = 0）
③**底盘水平**（G_s = 0）；令小 yaw **力矩 0 且静止**、忽略阻力 ⇒ `0 = −½μ(θ_s)Ω²` ⇒

```
★ μ(θ_s*) = 0  ⇔  Q(θ_s*) = R(θ_s*)·P ∥ d  ⇔  θ* = angle(d) − angle(P)
等效刚度 k = Ω²·|d|·|P|
```

**离心力把上装质心甩到"大 yaw 轴 ↔ 小 yaw 轴"连线的径向外侧**。该位置只由机械几何决定、
**与编码器零位无关、可重复** ⇒ 它是天然物理参考，测得它的编码器读数 `mapped_eq` 即得零位偏移。

## 2. ★ 两类系统误差、两套抵消手段（**两个都必须做**）

| 误差源 | 对 Ω 的奇偶性 | 抵消手段 |
|---|---|---|
| **静摩擦/粘滞带**（停在 θ* ± fc/k，取决于**从哪一侧逼近**） | **偶函数**（Ω→−Ω 不变） | **两侧交替逼近后平均** |
| **空气阻力等与 Ω 成正比的耗散** `τ_drag,s = −c(|Q|²θ̇_s + Ω(d·Q+\|Q\|²))` | **奇函数**（含线性于 Ω 的项） | **±Ω 双向平均** |
| **底盘倾斜**（重力项 G_s） | **偶函数** | ❌ 消不掉 ⇒ 只能**把底盘放平** |

### 2.1 确定性验证（`--sim` 输出原文；同一初始条件、同一 |Ω|、只差符号）

```
    阻力 c     停位(+Ω)(°)     停位(−Ω)(°)   (+Ω)−(−Ω)(°)        两向平均停位(°)      理论偏移(+Ω)(°)
     0.0     -6.560926     -6.560926       0.000000        -6.560926            0.000
     0.5     -8.152775     -4.903162      -3.249612        -6.527968           -1.056
```

* **无阻力**: 两个方向**完全相同**（差 = 0.000000°）⇒ 离心项 ∝ Ω² 是偶函数；
* **有阻力 c=0.5**: 两方向偏移**符号相反、大小相等**（各 ≈1.6°，解析解 ±1.056°），
  而**两向平均回到无阻力平衡点**（差 0.033°）⇒ **阻力靠 ±Ω 消**。

⇒ **两侧交替消"Ω 偶次项"（粘滞带/重力），±Ω 消"Ω 奇次项"（阻力）**，两者都做才干净。
凡是在"无未建模 Ω 奇次项"的模型里看到 ±Ω 完全等价，都只是模型过于理想。

### 2.2 单侧偏差与"没有信息量"的两种情形

```
单侧偏差 = fc/k = fc_small/(Ω²·|d|·|P|)   （粘滞带半宽; 左逼近停 θ*−fc/k, 右逼近停 θ*+fc/k）
```

* **起点落在粘滞带内**（距 θ* < fc/k）⇒ 小 yaw 根本不动 ⇒ 该次测量 = "起点本身"，
  对 θ* 没有约束。脚本记录 `moved_deg`/`stuck`，卡住过半时告警（提高 Ω 或加大 δ）。
  这也解释了实测"单侧偏差几乎与 Ω 无关（≈偏置大小）"：卡住工况下停位就是起点。
* **加速段冲量** `∫M12·θ̈_b dt = M12·Ω`（与斜坡快慢无关）: 自由松手时会被甩出
  `Δθ̇_s ≈ (M12/M22)Ω`。**摩擦能吸收的量是 fc·t_ramp** ⇒ `t_ramp ≥ M12·Ω/fc_small`
  ⇒ 与 Ω 无关地要求 **`accel ≤ fc_small/M12`**。本仓库参数（M12≈0.0178、fc=0.052）给出
  `accel ≤ 2.9 rad/s²`，故默认 **2.0**。仿真实测（自由松手、Ω=40）:

  | 加速段 | 加速段位移 | 最大 \|θ̇\| |
  |---|---|---|
  | accel = 8 rad/s²（快） | **−1085°**（甩飞 3 圈） | 10.9 rad/s |
  | accel = 4 | −6.6° | 0.99 |
  | accel = 2（默认） | −6.1° | 0.04 |

  `--spinup-hold hold` 用**相对保持**（目标=当前读数）替代自由松手，可把 accel 提到 8（快 4 倍）。

## 3. 每次测量（相对偏置）与参数

### 3.1 流程

```
第 1 次(θ̂ 未知) : 松手(τ=0) → 大 yaw 斜坡加速到 Ω → 等 Ω 稳定 → 等小 yaw 停住 → 采样窗口平均 ⇒ θ̂₀
之后每次        : 松手 → 加速到 Ω → 等 Ω 稳定 → ★此刻施加相对偏置 mapped_now ± δ（交替, 低力矩+失速检测）
                 → 松手 → 等收敛 → 采样窗口平均
收尾            : 相对保持(目标=当前读数) + 减速到 0
```

实际输出片段（`--sim --verbose`，真值只用于最后算误差）:

```
[+1Ω #0] 盲松手(首测) 起点= +2.864° δ=+0.00°(达成+0.00°) 松手= -5.765° → 停位= -5.763°(移动0.002°, 卡住)
[+1Ω #1] 右侧(高读数侧)逼近 起点= -5.765° δ=+4.32°(达成+4.01°) 松手= -1.784° → 停位= -5.293°(移动3.509°)
```

### 3.2 两侧交替 = 相对偏置的符号交替

`δ = ±U(--bias-deg-lo, --bias-deg-hi)`（默认 2°~5°），按重复序号交替取正负；
`--one-side` 固定同侧（对照实验，演示单侧偏差）。

### 3.3 Ω 怎么选

`Ω ≥ sqrt(fc_small/(|d|·|P|·Δ))`（要单侧偏差 ≤ Δ）；本仓库几何
（`|d|=0.03 m`、`|P|=0.0144 kg·m`、`fc=0.052 N·m`）: Ω=10→69.8°、20→17.4°、40→4.4°、
60→1.9°。⇒ 压到 5° 需 Ω≥37.4，压到 2° 需 Ω≥59.1。

### 3.4 相对偏置的力矩下限（为什么默认 0.25 N·m 而不是 0.05）

稳态 Ω 下把 yaw 推离平衡点要同时克服 **离心等效弹簧 + 静摩擦**:

```
τ ≥ fc + k·δ        （k = Ω²|d||P|）
```

本仓库参数 Ω=40、δ=5° ⇒ `0.052 + 0.683×0.0873 = 0.111 N·m` ⇒ **"接近 fc 的 0.05 N·m"推不动**
（脚本第一版就因此把每次测量都误判成失速）。默认取 **0.25 N·m**（≈5fc，远小于额定 1 N·m），
并按已知参数打印建议值。`--bias-kp` 必须能在目标误差处**饱和**（默认 4.0 N·m/rad），
否则 P 输出 ≈ 弹簧力、差一个 fc 就卡住。

## 4. 输出与"直接可用"的结果

* 终端: 每次原始值（起点读数、δ 与**实际达成**、松手角、停位、位移、卡住/失速）、
  **左侧均值 / 右侧均值 / 两侧合并**、**单侧偏差**、**仅+Ω / 仅−Ω / ±Ω 合并**、±Ω 差、
  实测极差、理论 fc/k、卡住次数、相对预算用量；
* `--out`（默认 `data/sysid/small_zero_calib.json` + 同名 `.csv`）;
* **零位建议**: `mapped = raw·scale + offset`，把物理平衡点定义为 0 ⇒ **`Δoffset = −mapped_eq`**；
  `--report-only` 只测不给建议;
* **★ 副产品**: 标定后模型里 **P = |P|·d̂**（若 `dy=0` ⇒ **Py=0**）—— P 的**方向**被物理标定
  确定、只剩模长待辨识（缓解"水平数据下 Px/Py 与惯量共线 corr≈−0.93"）。前提: d 方向可信、
  平衡点可达（在行程内）、底盘水平。标定误差 = θ* 估计误差 ⇒ P 的方向残差就等于它。

### 4.1 `--probe-travel`（标定后自检）

用**低力矩 + 失速检测**（Ω=0）在两侧慢慢推，摸到机械停止位，报告:

| 检查 | 期望 | 说明 |
|---|---|---|
| 行程宽度 W | ≈ **45°** | 不等 ⇒ **scale 不对**（脚本给出建议 `scale_new = scale×45/W`） |
| 平衡点 → +侧 | ≈ **+20°** | 不对称行程的自洽性判据 |
| 平衡点 → −侧 | ≈ **−25°** | 同上 |

仿真实测（行程内几何，`--probe-travel`）:

```
探针+侧: 停止位读数 =  +12.864°（失速 ⇒ 判定为机械停止位）
探针-侧: 停止位读数 =  -32.136°（失速 ⇒ 判定为机械停止位）
行程宽度 W = 45.00°（应 ≈45.0° ⇒ scale 校核通过）
平衡点到两侧: +18.79°（应 ≈20.0°）, −26.21°（应 ≈25.0°） ⇒ 自洽
```

（偏差 ±1.2° 正是本次标定的误差，与 §5 表里的误差一致 ✓）

3. **⑤ 卡住为主的工况**（Ω=10/20 时 fc/k=69.8°/17.4°）下误差与 Ω 弱相关、单侧偏差≈偏置起点均值；

4. **⑥ 倾斜 5°** 误差 1.323°（无倾斜时 0.302°）: 重力是 Ω 偶函数、**消不掉**，只能靠放平。

   慢斜坡（默认）与"加速段相对保持"都正常 ⇒ 默认参数选对了。

## 7. 操作清单: **标定前 vs 标定后**

| 事项 | 标定**前** | 标定**后**（写回 Δoffset 之后） |
|---|---|---|
| 绝对角度语义 | **不可用** —— 0 点未知，`[−25°,+20°]` 还不知道在哪 | 可用 —— 平衡点 = 0 rad ⇒ 行程 = `[−25°, +20°]` |
| 位置指令 | **只用相对偏置** `target = mapped_now + δ`；首测干脆不预置直接松手 | 可以正常用绝对目标（`collect_sysid.py` 的包络 `[−17°,+12°]`） |
| 电控小 yaw 限位保护 | **必须临时放宽/旁路**（否则按错误零点误判、把力矩清零）；脚本要 `--ack-mcu-limits-bypassed` | **恢复** `[−23°, +18°]` 的目标夹取 + 软限位 |
| 安全策略 | 相对位移预算 + 累计路径预算 + 失速检测 + 低力矩 + \|θ̇\| 上限 | 绝对行程守卫（采集脚本的 `[−25°,+20°]` 中止阈值） |
| 力矩上限 | `--bias-torque`（默认 0.25 N·m，只够"推几度"） | 额定 1 N·m（采集 PID 输出限幅） |
| 行程信息 | **不知道**离限位多远 ⇒ 任何"绝对守卫"都无意义 | 可用 `--probe-travel` 复核: W≈45°、到两侧 ≈+20°/−25° |
| 模型里的 P | 待辨识（水平数据下 Px/Py 与惯量共线） | **P 的方向已确定**: P = \|P\|·d̂（dy=0 ⇒ Py=0），只剩模长 |
| 采集脚本 | 建议先 `--report-only` 确认平衡点可达 | 正常采集（水平段 / `--tilted` 倾斜段） |

### 7.1 推荐操作顺序

1. **底盘放平**（脚本读 `est.gravity_a`；重力是 Ω 偶函数、消不掉）；
2. **临时放宽/旁路电控小 yaw 限位保护**（`--ack-mcu-limits-bypassed` 确认）；
3. `--omega=40 --repeats=3 --report-only --verbose`
   看: 卡住次数、左右均值差、是否出现"完全推不动"（撞限位/电控清零力矩）、相对预算用量；
   **先确认平衡点在行程内**；
4. 正式标定: `--omega=40~60 --repeats=5`（每侧 5 次 = 10 次），必要时 `--bias-deg-lo/hi` 调大到 > fc/k；
5. 可选 `--probe-travel` 复核行程宽度与到两侧距离（scale 与零点自洽性）；
6. 把 `Δoffset` 加到 `recv_small_yaw_offset`，**恢复电控限位保护**，
   用小幅手动/`--dry-run` 复核限位与方向；
7. 数据留档 `data/sysid/small_zero_calib.json/.csv`；**换装/拆装小 yaw 关节后重标**。

## 8. ★ 大 yaw 转速硬上限（2 s/圈 ⇒ Ω ≤ π）与两种方法的可行性

**用户明确约束: 大 yaw 标定转速最慢 2 s 一圈 ⇒ Ω ≤ π ≈ 3.1416 rad/s。**
脚本 `--omega` 默认与上限都取 π（传更大值会被钳到 π 并告警）。

### 8.1 复现的判定数字（`--sim` 打印，与用户手算一致）

| 几何 | k_cent = Ω²\|d\|\|P\| (Ω=π) | ±5° 内离心驱动力 k·5° | vs fc_small | 结论 |
|---|---|---|---|---|
| 占位几何（用户实测 \|P\|=0.01423） | 0.00421 N·m/rad | **0.000368 N·m** | 0.052 | **完全推不动** |
| 仿真几何 \|P\|=0.15 | 0.04441 | **0.003876 N·m** | 0.010 | **仍然推不动** |
| 要"±5° 内推得动"需 | \|d\|\|P\| ≥ fc/(5°·Ω²) | 占位几何需 **141×**；\|P\|×20 几何需 2.6× | — | 差 1~2 个数量级 |

单侧偏差 `fc/k` 在 Ω=π 下: 占位几何 **707.2°**、仿真几何 **12.9°** —— 都远超
`--max-acceptable-deg`（默认 5°）。脚本据此**直接判定不可行**并打印:

```
离心法 Ω≤π: fc/(Ω²|d||P|) = 707.151° ⇒ **不可行**（推不动/精度不够）
重力法: fc/(|P|·g·sinφ): φ=90°→ 21.343°, φ=60°→ 24.645° ⇒ **不可行**
刚度对比: k_grav(φ=90°)/k_cent(Ω=π) = 33.1×（φ 阈值 ≈ 1.73°）
★★ 结论: Ω≤π 与当前几何下都达不到 5° 精度 —— 离心法需要 |d||P| ≥ fc/(5°·Ω²)，
   重力法需要 |P| ≥ fc/(g·sinφ·5°)
```

**⚠ "误差很小"≠"标定准"**: Ω≤π 时小 yaw 根本不动 ⇒ 停位 = 起点 ⇒ 读数没有信息量。
脚本把 **`卡住比例`** 显式打印（`卡住=没被推动 ⇒ 读数就是起点, 误差小是假象、信息量为零`）
并写进 JSON（`stuck_ratio`）；`--sim` 的 A/B 两组就复现了这个假象
（A1 误差 −33.7° 但 3/3 卡住；B1 单次误差 +10.0°、B2 单侧多次 +19.9° 都只是"起点平均"）。

### 8.2 重力平衡法（`--method=gravity`，不需要转大 yaw）

把底盘**静态倾斜 φ**（把小 yaw 轴放倒接近水平），重力在小 yaw 平面上有分量 `g_A`:

```
平衡点: R(θ*)·P ∥ g_A（载荷"挂"在最低点, 像单摆）
刚度  : k_grav = |P|·g·sinφ          （与 Ω 无关, **也没有空气阻力**）
单侧偏差: fc/k_grav
```

与 Ω=π 的离心法比较: `k_grav/k_cent = g·sinφ/(Ω²|d|) = 9.81·sinφ/0.296`
⇒ **φ > 1.73° 重力法就比"2 s 一圈"的离心法强**；φ=30/60/90° 分别强 **16.6/28.7/33.1 倍**。
占位几何 fc/k_grav 从 707° 降到 **21.3°（φ=90°）**；|P|×20 几何降到 **0.39~0.78°** ⇒ 可行。

* **`--tilt-list`（默认 `90,60`）**: 平衡点**只由 g_A 的方向决定**（与倾角大小无关），
  所以不同倾角测的是**同一个物理点**，而它们的粘滞带 `fc/(|P|g sinφ)` 不同
  ⇒ **多倾角平均正好消掉粘滞带偏差**（与离心法的 ±Ω 完全对应，且没有阻力项）。
* **⚠ 关于"±φ 两个方向"**: 方向相反的两个倾角会让 `g_A` 反向 ⇒ 平衡点在**关节空间相差约 180°**，
  而行程只有 45° ⇒ **反方向那一侧不可达**，因此"±φ 直接平均读数"是不成立的
  （那是两个不同的物理点）。可用的替代就是上面的**多倾角大小平均**；机构不对称的偏差
  则靠"两侧交替 + 多次重复"消掉。
* **换算到与离心法同一个零点**: θ_c(水平旋转平衡点) = θ_g(倾角工况读数) + `angle(d) − angle(g_A)`
  （两个方向都已知 ⇒ 可直接换算）。脚本默认 `--zero-target=level`；仿真实测:
  `θ*_meas = +12.8645°` ⇒ **水平等效 θ*_level = −7.1355°**（真值 −7.135° ✓）。
* 真机操作: 脚本会提示把底盘摆到指定倾角，并从 IMU 读**实测** `|g_A|` 核对（不是假定值）。

### 8.4 `--probe-travel` 交叉校核（不依赖 P，Ω 受限时更可靠）

标定后用**低力矩 + 失速检测**（Ω=0、底盘放平）在两侧慢慢推，摸到机械停止位:

```

探针-侧: 停止位读数 =  -32.136°（失速 ⇒ 判定为机械停止位）
行程宽度 W = 45.00°（应 ≈45.0° ⇒ scale 校核通过）
平衡点到两侧: +18.79°（应 ≈20.0°）, -26.21°（应 ≈25.0°） ⇒ 自洽
```

* W ≈45° 做 **scale 校核**（不等则给出 `scale_new = scale×45/W`）；
* 到两侧的数字（≈+20° / −25°）是**信息性**的: ⚠ **`−25°/+20°` 这个分配本身来自尚未标定的
  电零点，不是独立机械事实** ⇒ **不能**用它来定零点、也**不再**作为"自洽性判据通过/不通过"；
  它只说明"当前零点大致落在行程的什么位置"。
* ⚠ 探针**必须在底盘放平 + 大 yaw 静止**时做: 否则重力会把小 yaw 拉向重力平衡点，
  把"推不动"误判成停止位（脚本会检测 `|g_A|` 并告警）。

## 9. 使用方式（用户澄清）与"零点可手动替换"

**问: 标定脚本不允许绝对输出，标定出一个值、手动写进别处之后，是否所有地方就都用这个值做绝对控制了？**
**答: 是的。** 一旦把 `Δoffset` 写进 `recv_small_yaw_offset`（或运行时 `setLinearParams`），
**全系统就在这个新零点坐标系里做绝对控制**:

* MPC 的小 yaw 限位 `[−25°, +20°]`、回中中心 −2.5°、电控 `[−23°, +18°]` 目标夹取、
  所有目标/参考/回中位置，**全部**是**这个新坐标系下的绝对角**；
* **`Δoffset` 写错 = 限位对应的物理位置整体平移**: 写大 3° ⇒ 真实可达行程变成
  "一边 28°、另一边 17°"（原本 −25/+20）。**所以改 offset 之后必须复核限位**；
* 标定脚本**自身不做绝对定位**（写 offset 之前坐标系无意义）—— 这点保留。

### 9.1 零点允许手动微调（`--zero-deg`）

`--zero-deg=<deg>`（等价 `--manual-offset`）的语义: **用户直接声明把零点挪这么多度**
（或声明"当前坐标系就是对的"）。此时脚本的职责变成:

1. 仍然测量平衡位置 `θ*_meas`（就在当前坐标系里，单位是编码器/映射角度）；
2. `Δoffset = −θ*_meas` 只是**建议值**，用户可以用 `--zero-deg` 改成别的值；
3. 把 **`θ*_meas` 这个相对量**记录进 JSON/CSV（后续辨识需要它，见 §9.2）。

### 9.2 ★ P 的方向约束（推广形式）

平衡条件是 `R(θ*)·P ∥ d`，因此**通用的 P 方向约束**是:

```
P = |P| · R(−θ*_meas) · d̂          （θ*_meas 用**当前/新坐标系**里的平衡点读数）
```

* 若零点 = 平衡点 ⇒ `θ*_meas = 0` ⇒ `P ∥ d`（原来的特例；`dy=0` 时 `Py=0`）；
* 若手动把零点挪了 δ ⇒ `θ*_meas = δ` ⇒ **P 相对 d 转了 −δ，不能再假设 Py=0**；
* 脚本输出 `implied_P_direction_offset_deg = θ*_meas`（在**新**坐标系里）与
  `P_direction_constraint`（上面那条公式的实例化字符串）。

> **给辨识/对比工具的话**: 若要用"P 方向已知"这个约束，必须用
> `P = |P|·R(−θ*_meas)·d̂` 构造，**不能**无脑写 `Py = 0` —— 只有当标定后零点恰好在
> 平衡点上（θ*_meas = 0）时 `Py = 0` 才成立。

```

`fc=0.0973, φ=90°` 实测输出:

```

**⚠ 配重法注意事项（已写进脚本输出）**: 加配重后平衡点是**总一阶矩 `P_tot = P_payload + P_w`**

才能得到"去掉配重后"的零点；本模式建议只用来 `--report-only` 测**方向**，零点必须按此换算。

### 10.6 本参数下的总体结论

1. **离心自由摆动法在 2 s/圈 的限制下不可用**（推不动 + 单侧偏差 565°）；
2. **重力法强 9.9 倍但仍不够**（fc/k = 56.8°），而且本参数下 θ* 还在行程外；
3. 想真正做成，按性价比排序:
   ① **减小 fc_small**（换脂/预紧/轴承）—— 最直接，线性收益；
   ② **挂已知临时配重** K≈20~30 倍（φ=90° 重力法）—— 注意 `P_tot = P_payload + P_w` 换算；
   ③ **`--probe-travel` 交叉校核**（不依赖 P，Ω 受限时最可靠）: 用低力矩 + 失速检测
      量出 W≈45° 与到两侧 ≈+20°/−25°，与标定结果互相验证；
   ④ 若精度要求可放宽到 ~7°，则**重力法 φ=90° + 多倾角平均**已接近可用边界（需更大 K）。
