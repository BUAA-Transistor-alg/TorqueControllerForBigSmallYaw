# data/archive/20260916_geom_0_007 — 新几何 `d = (0, 0.07)` 的辨识复核

> ⚠ **工具变更（2026-09 后期）**: C++ 线性最小二乘辨识工具（`tcbs_identify_params`）、
> 三方法对比脚本（`compare_ident_methods.py`/`eval_params_holdout.py`）与仿真数据生成脚本
> （`dump_sim_dataset.py`）**已从仓库删除** —— 现在只有 torch 一条辨识路径。
> 本目录里带 `ls_`/`ls_runs` 的输出是**当时的 LS 结果**，作为数据记录保留，**无法再复现**。
## 为什么有这一份

轴间距的实测值从占位值 **`(dx, dy) = (0.10, 0)`** 改成了 **`(0, 0.07) m`**
（横向无偏置、小 yaw 轴在大 yaw 轴**前方** 0.07 m）。

`d` 只以**耦合项**形式进入模型（`M12 = Js + d·Q`、`M11 = Jbig_eff + Js + 2·d·Q`、
`μ = ∂M11/∂θs = 2(dy·Qx − dx·Qy)`），因此几何一改，**`P` 的辨识结果会按 `1/|d|` 比例变化**，
`(0.10, 0)` 那批归档数据（见 `../20260915_sim_sysid/`）**不能再代表新几何**。
本目录用**当前仓库默认几何**重新生成一份小规模仿真数据，验证"换了 `d` 之后
整条辨识链（采集 → LS / torch → 参数误差）是否仍然成立"。

## 结果

### LS（`tcbs_identify_params`，`--held=measured --lambda=100 --smooth=3`）

| 参数 | 真值 | 估计 | 误差 | σ | 判据 |
|---|---|---|---|---|---|
| `Jbig_eff` | 0.050 | 0.0569 | +13.8% | 0.000725 | — |
| `Js` | 0.020 | 0.0132 | −33.8% | 0.000197 | — |
| `Px` | 0.0087 | **0.00840** | **−3.4%** | 0.000341 | **\|Px\|/σ = 24.6 ✓** |
| `Py` | 0.0050 | **0.00509** | **+1.9%** | 0.000357 | **\|Py\|/σ = 14.3 ✓** |
| `fc_big` | 0.220 | 0.2087 | −5.1% | 0.00387 | — |
| `fv_big` | 0.055 | 0.0685 | +24.5% | 0.00382 | — |
| `fc_small` | 0.0973 | 0.0844 | −13.3% | 0.00122 | — |
| `fv_small` | 0.028 | 0.0574 | +105% | 0.00447 | 已知的 LS 固有偏差 |

数值秩 8/8；加权残差 RMS 0.707 → 0.474。

**关键结论**: **`P` 在新几何下仍然可辨识，且 `|P|/σ` 远超 3 的判据**
（这正是几何改动最需要复核的一点）。LS 的 `Js`/`fv_small` 偏差是该方法本身就有的问题
（见 `docs/sysid_torch.md`：100 段水平数据下 LS 的 `Jbig_eff` 偏 +41~72%）。

### torch 输出误差法（`identify_params_torch.py`，λ=100、`substeps=4`、1000 epoch、用时 425 s）

| 参数 | 真值 | 估计 | 误差 |
|---|---|---|---|
| `Jbig_eff` | 0.050 | **0.050221** | **+0.4%** |
| `Js` | 0.020 | **0.020410** | **+2.1%** |
| `Px` | 0.0087 | 0.009945 | +14.3% |
| `Py` | 0.0050 | 0.004028 | −19.4% |
| `fc_big` | 0.220 | **0.220937** | **+0.4%** |
| `fv_big` | 0.055 | 0.052454 | −4.6% |
| `fc_small` | 0.0973 | **0.100975** | **+3.8%** |
| `fv_small` | 0.028 | 0.017961 | −35.9% |

`|P|` = 0.01073（真值 0.01005，**+6.8%**）；`P` 的方向 22.05°（真值 29.89°）。
loss 前 5 均值 9.05e-2 → 后 5 均值 7.01e-5（下降 ✓）。

**结论**: 惯量与库仑摩擦恢复到 0.4~3.8%，`|P|` 恢复 +6.8%（`P` 的方向误差是 20 段小样本
+ `fv_small` 偏差的联合结果，样本量上来会收敛）。`fv_small −35.9%` 与
`docs/sysid_torch.md` 记录的"即使 plant λ=1e5 也持续存在 −31~−38%"一致，
**属于模型/方法固有偏差，不是几何改动引起的**。

## 怎么复现

```bash
# ① 数据已在本目录；如需重生成（约 27 s）:
python3 python/scripts/dump_sim_dataset.py --out=data/archive/20260916_geom_0_007/datasets/sim20 \
        --n-per-axis=10 --tilt-deg=10 --plant-lambda=1.0e4 --plant-substep=2.0e-5

# ② LS（几何走仓库默认 (0, 0.07)，**不要**给 --dx/--dy）
TRUTH=Jbig_eff=0.05,Js=0.02,Px=0.0087,Py=0.005,fc_big=0.22,fv_big=0.055,fc_small=0.0973,fv_small=0.028
./build/tcbs_identify_params data/archive/20260916_geom_0_007/datasets/sim20/*.csv \
    --held=measured --lambda=100 --smooth=3 --truth=$TRUTH \
    --out=data/archive/20260916_geom_0_007/ls_measured_lam100.txt

# ③ torch（约 7 min，单核）
python3 python/scripts/identify_params_torch.py \
    --data='data/archive/20260916_geom_0_007/datasets/sim20/*.csv' \
    --truth-params=0.05,0.02,0.0087,0.005,0.22,0.055,0.0973,0.028 \
    --model-lambda=100 --substeps=4 --epochs=1000 --threads=1 \
    --plot-out=data/archive/20260916_geom_0_007/torch/ident_torch_lam100 \
    --out=data/archive/20260916_geom_0_007/torch/ident_torch_lam100.txt
```
