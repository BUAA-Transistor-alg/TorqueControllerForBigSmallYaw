# 20260920 — 水平 vs 倾斜：随机重心（小 yaw 上装 P + 大 yaw 转子 Pb）的辨识对比

> 用户要求: 模型加 `Pbx/Pby`；仿真环境让**小 yaw 上装**与**大 yaw 转子**都带随机重心偏置、
> 都受重力影响；采**地面平放**与**倾斜**两组数据（**刚性大 yaw**），对比两者的辨识参数误差。

## 0. 结论先行

| | 水平数据 | 倾斜 10° 数据 |
|---|---|---|
| **`Pb = (Pbx,Pby)`**（大 yaw 侧一阶矩） | **纹丝不动**（= 初值 0，\|Pb\| 相对误差 **0.00**）—— 水平时 `G_⊥≡0`，它的**梯度恒为 0**，数学上不可辨识 | **认出来了**: 方向误差 **0.3°~0.4°**，幅值偏大 **+20~28%**（`--beta-mode=fit` 时 +20%） |
| **`P = (Px,Py)`**（小 yaw 上装一阶矩） | **方向完全错**（86°/68°；幅值 1.25~1.36 倍纯属巧合） | **方向误差 7.2°/7.4°，幅值 0.92~0.95 倍**（−5~−8%） |
| 机械量（Jbig_eff / fc / fv / k / c / Jmotor …） | 两者相当（Jbig_eff +21%、k +29%、fv_big −19% …，见 §3） | 同上，倾斜**没有**让机械量变差 |

⇒ **倾斜是 P/Pb 可辨识的必要条件，而且对 P 是决定性的（方向 86°→7°）**；
`Pb` 则是"水平数据下恒等于初值"的典型不可辨识量。机械量与姿态无关。

> ⚠ 前提与解释见 `docs/backlash_model.md` §2.6: `Pb` **只**进大 yaw 行、`Gs` 同时进两行 ⇒
> 小 yaw 行是 `Pb` 的参照 ⇒ 两行联立时 `Pb` 与 `P` 可分（解析条件数 ≈2.6）。若只看大 yaw
> 通道（`--fit-axis=big`），则必须靠小 yaw **摆开**才能分开。

## 2. 辨识设置（`fits.sh`，4 个臂）

* 机械量初值 = **被控对象真值**（`Jbig_eff=0.050, Js=0.020, fc_big=0.220, fv_big=0.055,
  fc_small=0.0973, fv_small=0.028, δ=0.002, k=2500, c=2.0, Jmotor=0.006, fc_motor=0.030,
  fv_motor=0.010`）；**重心未知 ⇒ `Px=Py=Pbx=Pby=0`** —— 这样比的才是
  "重心参数能不能从这份数据里认出来"，而不是"初值猜得准不准"。
* 3000 epoch、`--batch-segments`、`--substeps=4`（k=2500 时 dt_eff=2.5 ms，刚度余量 2.4×）、
  `--state-mode=est`（控制器真正看到的状态）。
* 两个 β 口径: `auto`（用数据里的在线 β 列，= 运行期做法）与 `fit`（拟合一个全局常数 β，
  把无背隙时在线 β 的噪声拿掉）。

## 4. 解读

1. **`Pb` 在水平数据上梯度恒为 0**（`Gb ≡ 0`）⇒ 拟合值 = 初值，与数据无关（本目录里就是精确的
   `0.000000000`）。这是"**必须采倾斜数据**"的最硬理由，也是判据: 只采水平数据时
   `Pb` 那一列永远等于 `--init-vector` 给的值。
2. **`P` 在水平数据上方向全错**（86°/68°）—— 与文档里"水平数据下 Px/Py 不可辨识"一致
   （它只能通过 `d·Q` 耦合间接露头，`|d|=0.07` 太小）。倾斜后方向误差降到 **7°**、
   幅值 −5~−8% ⇒ **倾斜对 P 是决定性的**。
3. **`Pb` 的方向极准（0.3~0.4°）但幅值偏大 20~28%**。原因（见 §2.6 的解析）: 大 yaw 行里
   `Gs` 与 `Pb×g_A` 的 θ_p 依赖**同频**，二者之和 `(Pb + R(θs)P)×g_A` 才是大 yaw 行真正约束的量；
   把 `Pb` 从"和"里拆出来靠的是小 yaw 行（它只含 `P`）。而本批数据里大 yaw 段是**小 yaw 保持不动**
   的 ⇒ 拆分条件偏弱 ⇒ 幅值误差被放大（方向不受影响）。
   **改进**: 倾斜数据里让**小 yaw 也动起来**（不同 held 大 yaw 角下做小 yaw 段，
   即 `--held-big-stratified`，或在倾斜段里加油门到小 yaw 的激励）——那样 `(P, Pb)` 的拆分条件
   数会好很多。
4. **机械量两组相当**（Jbig_eff +21%/+25%、k +29%/+31%、fv_big −19%/−11%、δ 停在 0.0013
   附近而不是真值 0）；这些误差与姿态无关，属"模型结构误差"（`Jbig_eff` 一贯偏高、
   `fc/fv` 互相换位），不是这次要回答的问题。δ 停在初值附近再次印证"无背隙时 δ 不可辨识"。
