# fit4x — 「4× 仿真数据 + γ（背隙直通项）冻结」的 10000-epoch 结果（**修订版**）

> 用户要求：**把直通项系数固定成一个很小的值、不参与训练**；**仿真数据量加到 4 倍**；
> **重新训练 10000 epoch**，并再画一组曲线。
>
> ⚠ **本轮推翻了上一轮的方法学**：`collect_sysid.py` 对 `--seed` 是**确定性**的，我上一轮
> 用"另起一次运行"采的留出集与训练集**逐位相同**（8/8 重合），4 个并行采集进程也用同一个
> 默认 seed ⇒ 所谓"400 段"只有 100 条唯一轨迹。**上一轮所有标"留出集"的数字只能当训练集
> 拟合误差看**（`../fit10k/` 与 `../fit/` 里的留出数字已按此理解）。
> 现在辨识脚本内置了**训练/留出指纹重合检查**（1e-6 量化，兼容 CSV 六位小数）+ 采集脚本的
> `--seed` 警告，本轮开跑前自检输出：
> `训练段数=400 唯一=400 重复=0；留出 32 段中与训练重合=0`。

## 2. 训练（四个 10000-epoch 运行，同一个 32 段真留出集）

| 运行 | 数据 | γ | 状态目标 | 用时 |
|---|---|---|---|---|
| **A400**（主结果） | 400 段 | **冻结 0.002** | 估计值 | 4489 s |
| B100（数据量对照） | 100 段 | 冻结 0.002 | 估计值 | 4301 s |
| C400（γ 对照） | 400 段 | 自由（拟合） | 估计值 | 4491 s |
| D400（上限对照） | 400 段 | 冻结 0.002 | **真值** | 4539 s |

四个并行跑（各 4 线程）。

### 2.1 真留出集（32 段）开环 RMSE，窗口 0.1 s

| 运行 | 电机 | 云台 | 小 yaw | 整段 3 s 开环 电机/云台/小yaw |
|---|---|---|---|---|
| 初值（`planar_yaw_params.h`） | 1.323° | 0.287° | 0.914° | — |
| A400 γ冻结 400段 | **1.285°** | **0.198°** | **0.161°** | 3.99 / 3.37 / 1.32° |
| B100 γ冻结 100段 | 1.287° | 0.199° | 0.164° | 4.08 / 3.42 / 1.76° |
| C400 γ自由 400段 | 1.285° | 0.189° | 0.154° | 3.79 / 3.20 / 1.23° |
| D400 γ冻结 + **真值状态** | **0.717°** | **0.098°** | **0.085°** | 3.27 / 2.84 / 1.28° |

**读数**:
1. **γ 冻结几乎不损失精度**: A400 1.285/0.198/0.161 vs C400 1.285/0.189/0.154
   ⇒ 云台/小 yaw 差 4~5%，电机通道完全一样。
2. **4× 数据几乎没有收益**: A400 1.285/0.198/0.161 vs B100 1.287/0.199/0.164（差 ≈1%）。
   到 10000 epoch 时，限制来自**模型结构 + 电机角测量噪声**，不是数据量
   （学习曲线在 ~7000 epoch 后基本走平，见 `learning_A400.png`）。
3. **电机通道是测量噪声地板**: 初值 1.323° → 拟合后 1.285°（只降 3%）；
   一旦把**状态换成真值**（D400），同样 γ 冻结、同样数据，它直接降到 **0.717°**（−44%），
   云台 0.198°→**0.098°**（−51%）。⇒ 主运行的残差一半来自"电机角延时补偿估计"。

### 2.2 参数去向：**两条等价的路**（本轮最重要的结论）

| 参数 | 真值 | **A400（γ冻结）** | **C400（γ自由）** |
|---|---|---|---|
| `backlash_delta` δ | 0.0873 | **0.0163**（−81%） | **0.2543**（+191%） |
| `backlash_k` | ∞ | 51.1 | 107.1 |
| `backlash_through` γ | 0 | **0.002（冻结）** | 0.388（自拟合） |
| 死区内斜率 k·γ | — | **0.10** | **41.5** |
| 死区外斜率 k(1+γ) | — | 51.2 | 148.7 |
| `fc_big` | 0.220 | 0.2017（−8%） | 0.1992（−9%） |
| `fc_small` | 0.0973 | 0.0953（−2%） | 0.0963（−1%） |
| `Js` | 0.0200 | 0.0209（+4%） | 0.0209（+4%） |
| `Jbig_eff` | 0.0500 | 0.0549（+10%） | 0.0538（+8%） |
| `fv_big` | 0.0550 | 0.1256（+128%） | 0.1225（+123%） |
| `Jmotor` / `fc_motor` / `fv_motor` | 0.006/0.030/0.010 | 0.0051/0.0038/0.0034 | 0.0046/0.0038/0.0027 |

**δ 完全不可信，而且冻结 γ 也救不回来**：
* γ 自由时，模型把 δ 撑到 0.254 rad（14.6°）、γ 撑到 0.388（死区内 41.5 N·m/rad）；
* γ 冻结后，模型改走另一条路：**把 δ 压到 0.016 rad、k 降到 51**（死区内 0.10、死区外 51.2）；
* 两条路的**留出误差几乎相同**（1.285 vs 1.285 / 0.198 vs 0.189），也都远离真值
  （δ=0.0873、k=∞、γ=0）⇒ 在"接触面刚性 + 死区完全自由"下，
  **(δ, k, γ) 是结构上不可辨识的**：数据只能定出"工作范围内的平均顺应性"（~50 N·m/rad），
  定不出空程宽度。**只有 β 已知时 δ 才回到真值**（见 `../fit10k/` 的 β真值对照：δ +1.6%）。
* 平面参数（`fc_big/fc_small/Js`）在两种设置下都收敛到真值的 ±2~10%；
  `fv_big` 稳定地高 2.3 倍（未建模效应被粘滞项吸收，与实机数据同一现象）；
  `fc_motor` 稳定地低 8 倍（连真值状态的 D400 也是 0.0043 ⇒ 与冲击/约束建模失配有关，不是状态问题）。

### 2.3 闭环（被控对象 = 刚性接触 + 随机漂移 β，plant seed 7）

| 场景 RMS | E1 准确参数 | **E2 A400 拟合参数** | E3 A400 + β 真值 | E4 准确 + β=0 |
|---|---|---|---|---|
| 阶跃 0.6 rad | 0.0261 | **0.0271** | 0.0261 | 0.0258 |
| 大阶跃 1.2 rad | 0.1578 | **0.1598** | 0.1585 | 0.1581 |
| 正弦 0.3@0.5Hz | 0.0069 | **0.0065** | 0.0068 | 0.0067 |

失败数全 0、求解 1.3~2.2 ms ⇒ **γ 冻结 + 4× 数据后的参数控制这个刚性被控对象，与"准确参数"
只差 +3.8% / +1.3% / −5.8%**，与 γ 自由版本（0.0263/0.1632/0.0065）也几乎一样。

### 2.4 ★ 开环仿真 vs 实际采集（多段对比图）

`python/scripts/plot_openloop_compare.py`：只喂**记录的力矩**与**该段实测初值**，用识别参数做
前向仿真，和采集到的曲线叠在一起（每段一行：θ 叠加 / θ 误差 / θ̇ 叠加，标题里带 RMSE）。

| 图 | 数据 | 参数 |
|---|---|---|
| `openloop_vs_measured_A400.png` | **留出 32 段**里挑激励最大的 6 段（3 大 yaw + 3 小 yaw） | A400（γ冻结） |
| `openloop_vs_measured_C400.png` | 同上同一批段 | C400（γ自由） |
| `openloop_vs_measured_A400_train.png` | 训练集（`train_a`）里激励最大的 6 段 | A400 |
| `traj_A400.png` 等 | 留出集的 1 大 + 1 小（`identify_params_torch` 自动挑） | 各运行 |

这 6 段（**故意挑的最难子集**，不是 32 段的平均）实测：

| 参数集 | 窗口 0.1 s RMSE 电机/云台/小yaw（平均） | 备注 |
|---|---|---|
| A400（γ冻结） | **1.134° / 0.191° / 0.169°** | 角速度 0.484 / 0.060 / 0.054 rad/s |
| C400（γ自由） | 1.148° / 0.181° / 0.162° | 与 A400 基本无差别 |
| A400 在**训练集**同口径 | 1.040° / 0.218° / 0.200° | **训练 ≈ 留出 ⇒ 没有过拟合**（瓶颈在结构与噪声） |

**为什么整段 3 s 开环会漂到 3~9°（大 yaw 段）**：把开环误差与真值状态对照后可以看到，
刚性环境里 **Δ 几乎始终贴在约束面**（|Δ−β| = δ/2 = 0.0437，只在换向的几个 ms 里穿过死区），
而模型的接触是"软弹簧"（拟合后 δ=0.016、k=51）⇒ 两者在**换向处的耦合刚度不同**，
每次换向累积一点相位/幅值误差，3 s（3~7 次换向）下来就长到几度。
**小 yaw 段没有这个问题**（无背隙、直接驱动），整段误差只有 1~2.5°。
这也解释了为什么闭环没事：MPC 每 10 ms 用新测量重解，只依赖**短窗**精度（0.1 s 窗口 0.19°）。

## 4. 复现

```bash
# 采集（确定性；训练与留出的 seed 必须不同！）
C="python3 python/scripts/collect_sysid.py --dry-run --sim-rigid --duration-sec=3 --no-record-hold"
$C --segments=100 --seed=101 --out=train_a &   # 202 / 303 / 404 同理
$C --segments=32  --seed=555 --out=val
# 训练（四个运行之一）
python3 python/scripts/identify_params_torch.py \
  --data='train_a/*.csv,train_b/*.csv,train_c/*.csv,train_d/*.csv' --val-data='val/*.csv' \
  --epochs=10000 --batch-segments --substeps=2 --threads=4 --eval-every=250 --print-every=250 \
  --beta-mode=auto --state-mode=est --backlash-through=0.002  # γ 默认已冻结 \
  --plot-out=.../A400/ident --out=.../A400/params.txt
# 对比图
python3 python/scripts/plot_ident_compare.py --log='A400.log,C400.log' --out=compare_gamma.png
# 闭环
./build/tcbs_mpc_param_eval --plant-rigid --plant-beta-random=0.0262 --plant-beta-drift=0.0044 \
  --plant-beta-period=30 --plant-seed=7 --phi=<8参> --phi2=<背隙8参> --dump=.../mpc
python3 python/scripts/plot_mpc_tracking.py --csv='mpc_fit_*.csv' --out=mpc_tracking_fitted.png
```
