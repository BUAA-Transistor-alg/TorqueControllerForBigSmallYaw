# 20260920 — 「没有背隙」的仿真数据（仿真环境 3）+ δ 可辨识性对照

> 用户要求: **在当前结构下**（3-DOF + 16 参模型、现在的采集/辨识脚本）造一个**没有背隙**的仿真，
> 做一次辨识 —— 看这套流程会不会在"其实没有空行程"的数据上"认"出一个假的死区。
>
> 结论先行: **默认口径（`--beta-mode=auto`，用在线 β 列）下不会 —— δ 基本停在初值上，
> 0.0018~0.107 rad 都能拟合得差不多；换成 `--beta-mode=fit`（拟合一个全局常数 β）后，
> 损失强烈偏向"δ≈0、β≈0"的唯一解**（留出整段开环 0.22° vs 别的臂 2.3~14.7°）。
> 但从"假的大 δ"初值出发，**10000 epoch 也走不过去**（δ 只动 11%，残差靠着 `c`/`Jmotor`
> 补偿，仍是真解的 6.9 倍）⇒ δ 在这个方向上**梯度≈0（不可辨识）**，不是收敛慢。
> 详见 §4。

## 1. 环境（`collect_sysid.py --sim-no-backlash`，本次新增）

| 项 | 值 |
|---|---|
| 被控对象 | `PlanarYawPlant(backlash_delta=0.0, backlash_k=200, backlash_c=2, backlash_through=0.002)` |
| 传动 | **没有空行程**: `τ_t = k[dz(Δ)+γΔ]+cΔ̇`，δ=0 ⇒ `dz(Δ)≈Δ` ⇒ `τ_t ≈ k(1+γ)Δ + cΔ̇ = 200.4Δ + 2Δ̇` |
| 其余 | 与默认 dry-run 完全相同（录制序列激励 + PID + 分轴 + 保持段 + 同一套记录列与链路模型） |
| 采集 | `--dry-run --sim-no-backlash --segments=16 --out=train`；留出 `--segments=4 --seed=555 --out=val` |
| 数据量 | train 16 激励 + 15 保持 = **31 个 npz**；val 4 + 3 = **7 个 npz**（每段 300 点 @100 Hz，保持段默认截前 3 s） |
| 数据标记 | npz 里新加标量 `no_backlash=1` |
| 被控对象真值 | 平面/电机侧 = 默认那组（Jbig_eff 0.050, Js 0.020, Px 0.00866, Py 0.005, fc_big 0.220, fv_big 0.055, fc_small 0.0973, fv_small 0.028, Jmotor 0.006, fc_motor 0.030, fv_motor 0.010）；**背隙真值 δ = 0**（k/c/β 在这份数据里没有物理意义） |

## 2. 先看清楚「模型真正吃到的是什么」

| 量 | 统计 |
|---|---|
| 物理相对角 `Δ_true = θ_m,true − θ_p,true` | **±0.0048 rad（±0.27°）**，std 0.0011 ⇒ 只有同步带弹性变形，**完全没有空行程** |
| 记录列 `Δ_est = θ_m,est − θ_p,est` | ±0.131 rad（±7.5°），std 0.0127 |
| 在线 β（`backlash_center` 列） | std 0.0087，**范围 ±0.055 rad** |
| 模型实际输入 `Δ−β`（真值状态 / 估计状态） | ±0.060 / ±0.125 rad |
| 模型默认 δ=0.0965 的死区半宽 | 0.0483 rad |

⇒ 这份数据**物理上没有死区**，但"模型输入"被两样东西撑到 ±0.06~0.13 rad：

1. **无背隙时 `backlash_center` 本身就是噪声**：它是 Δ 的滑动 min/max 中点，没有真实死区时
   极值由测量/估计误差决定 ⇒ 自己就占 ±0.055 rad，**与 δ/2 = 0.048 同量级**；
2. **dry-run 的 MCU2 链路模型比真机旧 ~50 倍**：仿真 `big_enc_age` 中位 **50 ms**
   （95% 100 ms；链路间隔 80–120 ms），而真机实测 `big_sample_interval` 中位 **2.0 ms**、
   `big_enc_age` 中位 **0.8 ms** ⇒ 仿真里电机通道估计误差 std **0.033 rad（1.9°）**，
   比真机那条误差大一个量级以上。

⇒ **"无背隙仿真"对 δ 而言并不干净**（仿真噪声本身就有一个死区那么大）。这一点是本次实验
暴露的**仿真保真度问题**，见 §5。

### 4.1 默认口径下，δ 认不出来（= 停在初值上）

A/B/C 三个臂除了 `(δ,k,c)` 初值以外**完全同数据、同配置**，δ 初值相差 50 倍（0.002 / 0.03 / 0.0965），
拟合后仍是 **0.0018 / 0.0367 / 0.1068（各自离初值 ±10% 以内）**，而窗口 RMSE 只差 1.2 倍
（2.03e-2 / 2.37e-2 / 2.20e-2）——**"假的大 δ"甚至是三者里 loss 最低的**。
⇒ 在这份数据上，**δ 的最终值由初值决定，不由数据决定**。

机制（两条同时成立）：

* **结构性**: 只要 `δ_model > 2·max|Δ−β|`，模型从不离开死区 ⇒ `τ_t = k·γ·Δ`（γ 冻结 0.002）
  ⇒ δ 的梯度≈0；而 (δ 大, k 大) 与 (δ 小, k 小) 能给出同样的内部刚度 ⇒ 简并；
* **仿真数据不干净**: 见 §2 —— 在线 β 噪声（±0.055）与电机通道误差把"模型输入"撑到 ±0.06~0.13 rad，
  和 δ/2 同量级 ⇒ 模型**总能**用死区解释掉这些误差（所以大 δ 反而把电机通道残差压得更小：
  0.666° vs 0.884°）。

### 4.2 换成 `--beta-mode=fit`，数据立刻指向"没有背隙"

G/H 与 F/E 的唯一区别是 β 来源（拟合一个全局常数 vs 用在线列），其余相同：

* H（小 δ 初值）: δ → **0.0014 rad = 0.08°**（≈0 ✓），k → 258，c → 1.76，**β → +0.00023（≈0 ✓）**，
  窗口 RMSE 0.019/0.006/0.011°，**整段开环 0.22/0.22/0.56°**，loss **4.5e-5**；
* G（大 δ 初值）: δ → 0.0892（几乎没动）、β → +0.0461（跑到 0.046 去"贴边界"），
  loss 1.16e-3 —— **比 H 差 26 倍**，整段开环差 ~19 倍。

⇒ **模型能表示"没有背隙"（δ→0 的极限），损失也确实偏向它；把在线 β 这个噪声源拿掉之后，
δ 是可辨识的** —— 前提是初值别离真相太远。

### 4.2b 加练到 10000 epoch 也走不到真相（⇒ 是"梯度≈0"，不是"走得慢"）

G10k = G 的初值 + β 拟合 + 真值状态，但 10000 epoch（用时 923 s）:

* δ: **0.0965 → 0.0860（只动了 11%）**，β 卡在 **+0.0447**（跑不掉）；
* 它用别处补偿: **c: 2.59 → 5.36（×2）**、**Jmotor: 0.006 → 0.0219（真值 0.006，×3.6）**、
  k: 157.8 → 102.3；
* loss 3.49e-3 → **3.07e-4**（比它自己 1500 epoch 好 11 倍，但仍是 **H 的 4.5e-5 的 6.9 倍**）；
  留出整段开环 **1.82°**，而 H 是 **0.22°**。

⇒ 结论: **δ 那个方向基本没有梯度**（工作点贴在死区边界上、`∂loss/∂δ ≈ 0`，原始空间里
10000 步只走了 0.115 ≈ 3e-4/步的 1/26），优化器只能把残差塞进 `c` 和 `Jmotor`。
所以"无背隙数据上 δ 认不出来"**不是收敛慢，而是这个方向上损失面是平的**。

### 4.3 判据：窗口 RMSE 分不出来，**整段开环 RMSE 分得很清楚**

窗口 0.1 s 的 RMSE 在所有臂都在 0.02~0.9°，肉眼分不出真假 δ；而**整段 3 s 开环**：
H 0.22° ≪ B 2.3° < E 2.4° < G 4.2° < F 5.2° < A/C 7.4° < D 14.7°。
⇒ 判断"到底有没有背隙"要用**整段开环**（`plot_openloop_compare.py`，本目录每臂都有
`*_openloop_val.png`），不能只看窗口或训练 loss。

### 4.4 平面/电机那 11 个参数

从"接近真值"的初值出发，识别得不错（相对真值）: fc_small ±4%、fv_small −1%、fc_big +6%、
fv_big +1%、Js +6%、Jmotor ~±20%（库仑/粘滞互换），但 **Jbig_eff 系统性 +7~30%**；
从**实机默认值**出发（臂 D）1500 epoch 根本走不到仿真真值（fc_big 0.10 vs 0.22、
fv_big 0.181 vs 0.055、Js 0.0113 vs 0.02）——与之前"log 参数化 + lr=3e-4 每小时只能走
~1 个 e 倍"的观察一致：**换场景重新辨识，初值不能离真值 2~3 倍**。

## 5. 暴露出的仿真保真度问题（建议修）

`SimRobotLink` 把 MCU2 链路建模成 **~10 Hz、间隔 80–120 ms**
（`self._next = int(self.rng.integers(8, 13))`，见 `collect_sysid.py`），
而真机实测 `big_sample_interval` 中位 **2.0 ms**（5%~95% [1.84, 2.17] ms）、
`big_enc_age` 中位 **0.8 ms**。

后果: **所有 dry-run 数据**里电机通道的估计误差（std 0.033 rad = 1.9°）远大于真机，
连带把在线 β 也变成 ±0.055 rad 的噪声 —— 这恰恰是本次"δ 认不出来"的第二个原因，
也会影响历史归档里所有 dry-run 实验对 δ/β 的结论（那些结论作为"最不利情形"仍然成立，
但不要把其中的 δ/β 当作真机水平）。

建议: 把链路模型改成与实测一致的 2 ms 间隔（或加 `--sim-link-interval-ms`），
再重跑本目录的对照 —— 预期 A~F 的差别会显著变小、δ 的可辨识性变好。
